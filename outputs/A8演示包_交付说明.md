## 三、目标机三步

```powershell
# ① 装 Python 3.10+（推荐 3.12/3.13，64 位，勾选 "Add python.exe to PATH"）
#    解压到纯英文路径，如 D:\A8_demo

# ② 建环境 + 自检（约 3–5 分钟，首次需联网）
powershell -ExecutionPolicy Bypass -File setup.ps1

# ③ 采集环境快照（彩排第一件事，也是要归档的证据）
powershell -ExecutionPolicy Bypass -File scripts\collect_env.ps1
```

启动顺序（**不能反**）：

```powershell
.venv\Scripts\python.exe -m bci_decoder.cli run --config configs\demo_game_ws.yaml
#   ↑ 等它打印 idle（源机 13 s，新机器可能 20 s+）

.venv\Scripts\python.exe -m game.platformer.main --mode ws --ws-url ws://127.0.0.1:8765 --timeout 1.5
```

## 四、新机器上必须注意的四件事

1. **冷启动更慢**：机械盘或装了杀毒软件的新机器可能 20 s 以上，别在 13 s 没出来就以为挂了。
2. **首次要编译 pyc**：第一遍慢、第二遍正常，**彩排至少跑两遍**。
3. **切英文输入法**：黄凯森版没有 IME 兜底，中文输入法会吃掉 W/D 键 → 现场 `Win+Space` 切到「英」。
4. **纯英文路径**：别放 `桌面\新建文件夹`，用 `D:\A8_demo` 这类。

## 五、没网怎么办

在有网电脑上：

```powershell
pip download -r requirements.txt -d wheels
```

把 `wheels\` 一起拷到目标机，安装改为：

```powershell
.venv\Scripts\python.exe -m pip install --no-index --find-links wheels -r requirements.txt
```

## 六、回滚

源机 `D:\校企合作项目\bci-decoder` 保持可用不要动；两台机器命令完全一致，目标机故障直接换回源机。
换机演示时，归档的环境快照必须是**目标机**的 `hostname` 与 Python 版本（`collect_env.ps1` 已自动记录）。
