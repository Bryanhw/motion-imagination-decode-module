### T3 首证进度（2026-11-26 更新）

- **S01 两个 session 已下载完成且 MATLAB 头验证通过**（session1 609,007,751 B / session2 610,856,419 B），落 `.deepworks/mne_data/MNE-lee2019-mi-data/...`（不入库）。
- **8 通道契约导入验证通过**：直连 `scipy.io.loadmat` 读取手工 `.mat`（**绕开 moabb 1.7.2 的 nemar-py 下载层**——其 `get_data` 会按 NEMAR 布局误判缺失触发 1.14G 全量重下），62 通道 → pick 契约 `C3,Cz,C4,CP3,CP4,P3,P4,Oz` **8/8 命中顺序一致** → 1000 Hz 重采样 250 Hz → epochs (100, 8, 1000)，left/right 各 50 均衡。
- **基线首证（2026-11-26 首个真实数字）**：session1 训练 **N=20/类** → session2 测试，CSP(4,log)+LDA(lsqr,shrinkage)，口径沿用 M4 D1（notch50+bp8-30(4)+CAR、窗 2.0s/0.5s、cue 后 250 点起）→ 每试次 3 窗。结果：**窗口级 Kappa +0.280（acc 0.64）**、**trial 级投票 Kappa +0.300（acc 0.65）**。
>   - **口径脚注**：CSP 加 `reg='oas'`（Ledoit-Wolf 收缩），因 8 通道 CAR 后协方差必然秩亏（空间去均值 → 秩≤7），`reg=None` 经验协方差触发 `eigh` 非正定错误；收缩正则化不改变 CSP(4,log) 特征本质，仍与 M4 D1 对齐。
>   - **诚实解读**：远高于随机（随机 Kappa≈0），贴近但略低于 M3/M4 的 0.3 达标线——8 通道 + 40 试次 + 跨 session 是合理预期，属工程首证而非性能达标。**Kappa 为内部工程证据，不对外报告任何准确率（红线 5/6/7）**。

## 三、关键信息：如何“承接”8 通道契约

1. 每个库从 MOABB 读出后，**pick 到在线契约 8 通道**（存在公共标签名差异的做一次别名映射）；
2. 缺的通道（如 2b 只有 C3/Cz/C4）则**只取交集通道**训/评，**不凭空补通道**（红线：通道顺序即语义，不得“顺手重排”）；
3. 采样率统一重采样到 250 Hz（在线契约规格）；
4. 评估沿用 trial 级 Kappa / ITR 口径，**不对外报裸准确率**。
