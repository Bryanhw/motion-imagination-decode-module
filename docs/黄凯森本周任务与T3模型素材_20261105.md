## 可直接并入演示稿的模型解释

**30 秒口播：**“我们先用公开脑电数据检验左右手运动想象的分类。CSP 路线把多通道脑电投影为少量有区分力的空间特征，再交给 LDA；另一条离线比较路线用通道协方差和切空间特征。两条路线的结果都要写清训练与测试如何分开。今天游戏中的合成信号只演示决策消息能驱动角色，不能拿来证明真实脑电分类效果。”

**逐窗和逐次试验：**伪在线记录采用 cue 起 2.0 秒窗口、0.5 秒步长，每个 trial 有 3 个窗口。演示时若讲 trial 级结果，应说明对 3 窗做汇总；单窗结果和 trial 结果不可混称。伪在线与离线的差值是在比较两条处理路径的一致性，不是识别准确率本身。

**模型边界：**M3 真实数据评测使用 BCI IV 2a 的 22 个 EEG 通道；M2 游戏工程演示的冻结配置使用 8 通道和合成 mock 模型。离线黎曼评测结果没有自动部署到游戏，不能把游戏画面说成“黎曼模型实时控制”。

## 答问要点（提交讲稿负责人审阅）

| 被问到 | 建议回答 |
|---|---|
| 为什么游戏能动，还不能说脑控模型达标？ | 游戏录屏证明消息、WebSocket、动作映射和断线安全；分类效果要看真实公开 EEG 的独立测试。 |
| 为什么早期结果较好，严格测试却不达标？ | 早期四类混合 session 的 5-fold 与当前二类 `0train→1test` 是不同试题；报告须并列标注，不能替换。 |
| 什么是 Kappa？ | 扣除随机一致性影响的分类指标；目标 `>0.3`，并非“准确率 30%”。 |
| `idle` 代表识别出静息吗？ | 在本系统中代表这次不发动作，也可由低置信、模型未就绪或安全状态触发。 |
| 为什么要 3 窗投票？ | 每个 trial 的多个短窗可能波动；汇总能减少单窗偶然结果。须同时说明它增加等待，不能拿 trial 结果冒充单窗实时表现。 |
| 两台电脑已经完成 A8 联动了吗？ | 已归档的三段 A8 视频使用 `127.0.0.1`，证明本机联动。两机局域网演示仍无录像证据。 |
