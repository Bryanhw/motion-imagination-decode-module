# 设备通道诊断与三方案定夺（2026-11-17）

> 触发：组长诊断——当前 XMuse（位点 `TP9 / AF7 / AF8 / TP10`，前额+耳后）对左右手运动想象“换哪种想象、信号都只挪几毫米、够不着位点”。
> 任务：分析 ①换更好设备 ②用公开左右手想象数据集（含本地天津大学 MetaBCI 素材） ③更换方案（换任务范式）的三个备选，利弊 + 定夺 + 整理成文档。
> 性质：团队内部决策材料（含工程判断，**不对外报准确率**，红线 5/6）。

---

## 0. 结论提要（定夺一览）

1. **组长的诊断是对的，物理上成立**：左右手运动想象的可解码脑波（`mu` 节律 ERD/ERS，约 8–13 Hz 及其 `beta` 谐波峰值）主要发源于**中央感觉运动皮层（C3 / C4 / Cz 一带）**，只在很小的脑区范围衰减快。`TP9/TP10`（耳后）、`AF7/AF8`（前额）**远离该脑区**，等效于“天线朝向不对”——不是算法不行，是传感器位点物理上采不到手部想象信号。
2. **任何方案的第一判据，就看电极位点能否覆盖 C3/C4（或至少中央区）**。不看品牌、不看“更贵”。
3. **定夺：主推方案②，并行争取方案①，方案③仅兜底（需改契约）**。
   - **方案②（公开数据集）＝现在就能走、不依赖任何外部**，且数据恰是从“正确的天线位置”（C3/C4/Cz）采的，信号质量优于手头 XMuse；既有验收 A8 已有“合成/mock 解码可玩 + 受控数据回放”的先例口径，方案②可顺路把“解码→可玩”演示与里程碑③公开评测一并推进。
   - **方案①（换设备）＝最优解线但高度不确定**：必须先在老师处确认“新设备电极放哪里”，**只有覆盖 C3/C4/Cz 才值得等**；否则换了还是同一位点（消费级 XMuse 全系都是 TP9/AF7/AF8/TP10）。
   - **方案③（换范式）＝最后手段**：本次若走 ③ = 改动冻结契约（类别/滑窗/输出字段），必须走 `docs/MVP规格说明书.md` §9 变更流程 + 重排红线，代价最大。

## 1. 为什么 XMuse（TP9/AF7/AF8/TP10）够不着左右手想象（确认诊断）

### 1.1 神经生理事实（确定）

- 左右手**运动想象**在脑电上的标志是：想象右手 → 左半球 C3 区 `mu/beta` ERD（对侧去同步）；想象左手 → 右半球 C4 区 ERD。**信号源头集中在中央诱发/感觉运动区**。
- C3、Cz、C4 是国际 10-20 系统里的**中央感觉运动位点**；CP3/CP4、P3/P4 是辅助判据（稳定性）；Oz（枕叶）用于对照/伪迹关系（本项目冻结 8 通道 `C3,Cz,C4,CP3,CP4,P3,P4,Oz` 正是按此挑选）。
- 脑电从皮层到头皮经过颅骨衰减，空间平滑性强：**离源脑区越远的电极，信噪比恶化得越快**。手部代表区离 AF7/AF8 很近（前额），离 TP9/TP10（乳突）也在 5 cm 以上且跨越骨缝——测不到可判读的手部 ERD。

### 1.2 对照：这台设备能干与不能干（重要边界）

| 能可靠做（靠近前额/耳后，位点合适） | 不能可靠做（位点够不着） |
|---|---|
| 眨眼前额肌电、咬牙/咬肌伪迹、肌前额张力 | **左右手运动想象的 mu/beta ERD** |
| 某些前额/情绪/注意类慢电位研究（弱信号，另议） | Oz 枕区 alpha/SSVEP（**没有 Oz 电极**，前额做 SSVEP 极弱） |
| EEG 基础测量、静息评估 | CP3/CP4、P3/P4 中央顶区节律 |

> 一句话：**这台 XMuse 是一台“前额+耳后”消费级设备，不是左右手 MI-BCI 的正确传感器**。用它硬做，只会长期出 `idle`（红线 1 的正确行为），项目停在无法交付真采闭环的状态。

## 3. 方案①：换更好的设备

### 3.1 可行性判据（先问位点，再谈型号）

在向老师确认之前，**什么都不要等**。需要书面确认的硬判据（升级版 RA2）：

1. **电极位点**：新设备是否含 **C3/C4（最好含 Cz、CP3/CP4）**？——有则可用；没有（即便是另一个 XMuse 型号）则与现状无差别。
2. 通道数：≥8 且能对齐冻结 8 通道（C3,Cz,C4,CP3,CP4,P3,P4,Oz）；若只有中央区 4–8ch 且够 8 通道映射也可谈（走 §9 小变更）。
3. 采样率（≥250 Hz 与冻结滑窗/sfreq 口径匹配）、导出通道顺序（红线 4）、数据出口（LSL/厂商 SDK/离线导出）。
4. 交付与归还时间、能否带给团队机器（Q 现场）。

### 3.2 利弊

- **利**：唯一能拿到“本团队设备真采→真脑控”证据的路径；与项目灵魂定位一致；后续所有训练/评测/演示链路已有存续基础（calibrate/precheck 就绪）。
- **弊**：**老师只確认“是 XMuse”，型号/位点未知**——若还是消费级 XMuse（全系 TP9/AF7/AF8/TP10），方案直接无效；周期不可控（“有”，≠“能马上给”）；即使位点对，仍需重走采集/标注/校准闭环，工作量大。

> **建议**：**并行去要**，但**不阻塞**主推线。给老师的问题是：“电极戴在哪些位置/有没有 C3、C4、Cz？”，而不是“什么型号”。

## 4. 方案②：用公开左右手运动想象数据集（主推）

### 4.1 本地素材核实（已确认）

- 工作区外的 `D:\MetaBCI` 是**天津大学 MetaBCI 官方仓库克隆**，自带的 `metabci.brainda.datasets` 提供 9 类公开数据集的**加载器**，与本项目直接相关的：
  - **PhysioNet motor movement/imagery**（`physionet.py`）：国际公开 MI，**standard_1005 标准位点（含 C3/Cz/C4/CP3/CP4/P3/P4/Oz）**，可完整映射冻结 8 通道；
  - **BCI Competition IV 2a / 2b**（经 `bnci.py`/braindecode）：2a 为 22 通道含中央区；2b 为 **C3/Cz/C4 三通道**（少、不完整，慎用）；
  - 另含 `cbcic.py`（中文 BCI 竞赛类）、`alex_mi.py`、`schirrmeister2017.py`、`tunerl.py` 等 MI 加载器，以及 P300/SSVEP 类（方案③才会用）。
- **注意**：`D:\MetaBCI` 是**代码仓库，不是原始数据**；`~/.cache` 下未发现已下载的 EEG 缓存 → **首次使用需联网下载一次**（数据下载到 brainda 默认数据根，可用环境变量指定）。

### 4.2 落地路径（若拍板，我按此执行）

1. **选数据集**：优先 PhysioNet（位点最全、8 通道可完整对齐）或 BCI IV-2a；确认标注（left/right 二类 + idle）。
2. **导入管线**：新建 `scripts/m4_public_mi.py`（或扩展 precheck）——用 `metabci.brainda` 拉取→`mne` 重采样/滤波→**选冻结 8 通道子集**→按冻结契约导出（`t_data/t_wall/label/label_id/...` 字段不变，红线 3）。
3. **训练与评测**：沿用 csp 线（与黎曼对照）训练分类器；**评测按里程碑③公开口径走，数字只留内部证据，不对外**（红线 6）。
4. **演示链路**：数据集回放 → `jsonl/ws` 伪在线（复用 M3 伪在线能力 + 既有 WS 输出）→ 游戏可玩演示（与既有 A8“受控数据/mock 解码可玩”先例同口径，**性质标注清楚是公开数据回放、不是真采**，红线 5）。
5. **真采回归口**：一旦方案①设备到位，同一份训练/评测代码切换 source 即可（通道集合保持冻结 8 通道）。

### 4.3 利弊

- **利**：**零外部依赖、可立即推进**；数据来自正确位点、公开可复现；一步同时推进“解码可玩演示”与里程碑③公开评测两块交付；代码与在线契约完全兼容，真采回归零摩擦。
- **弊**：**不是“本设备真采脑控”**——不能单独满足“真实脑电真控制”的最强验收诉求；对“本团队设备能真控”无证据；需守红线边界（不冒充真采、不对外报数字）。

> 这是**能把项目往前推、且迟早都要做（里程碑③）**的一步；即使方案①成了，方案②的管线/评测也复用。

## 5. 方案③：更换方案（换范式）

### 5.1 可选形态与成本

| 形态 | 可行性 | 与项目定位的关系 | 成本 |
|---|---|---|---|
| SSVEP（视觉稳态诱发电位） | ❌ 设备无 Oz/枕叶电极，前额做 SSVEP 极弱 | 换任务 | 改契约 + 重新采集 |
| 眨眼/咬牙控制 | ✅ 这台能做（前额肌电强） | **“运动想象解码”名存实亡**，退化为肌电开关 | 同上；但技术上最快 |
| 静止 alpha 抑制/增强（神经反馈 on/off） | ⚠️ 勉强（前额有全局 alpha） | 远离“左右手想象意图”定位 | 同上 |

### 5.2 结论

**本轮不建议启动方案③。** 换范式意味着：冻结契约（2 类+idle、滑窗、输出字段）基本全废，需走 `docs/MVP规格说明书.md` §9 变更流程 + 重排红线；且除“眨眼”外都没有比得上现有预案的可行候选。只有当 ①设备位点确认不可行、②公开数据集双线都无法满足验收诉求时，才把它拿出来谈——“万一”再谈，不预支工程。
