## 摘要

本项目面向翔宇医疗"在线脑电信号处理与运动想象解码"课题，以**工程复现**为定位：基于公开运动想象 EEG 数据集，复现"预处理 → CSP 特征 → LDA 分类 → 在线回放解码"的经典管线，将"想象左手/右手握紧"解码为两条计算机指令——**左手=切换选项、右手=确认选项**——并通过一个**网页版 App** 进行可视化交互演示。项目以**时效性（低延迟响应）**为核心卖点：通过"窗长 × 准确率 × 推理延迟"权衡实验确定最优在线参数，实测并优化从"想象发生"到"界面响应"的端到端延迟。预期交付：可运行的解码模块、网页 App 演示系统、时效性实验报告与完整过程证据链。

## 1. 问题背景与意义

### 1.1 课题背景
非侵入式脑机接口（BCI）通过头皮 EEG 获取大脑活动，但信号微弱，易受眼电、肌电、运动与环境噪声干扰。**运动想象（Motor Imagery, MI）**范式利用一个关键事实：人即使不真正移动肢体，仅在大脑中想象肢体运动，大脑运动皮层的电节律（μ/β 节律）也会发生可检测的变化（ERD/ERS 现象），从而可以"猜"出用户在想象哪一侧肢体。企业关注的完整链路为：

> 原始 EEG → 滤波 → 预处理 → 特征提取 → 分类 → 运动意图

### 1.2 真实痛点：在线化与可感知性
企业在游戏、轮椅、康复设备等场景中要求系统**在很短时间内持续给出稳定判断**，即难点在**在线实时性**：低信噪比、个体差异、跨次漂移之外，"解码够不够快"直接决定产品可用性。同时，算法成果若不能以直观方式被非专业用户感知（看见、玩到），其价值也难以传达。

### 1.3 我们的切入点
作为大一团队，我们不追求算法创新，而是**把教科书级方法做成一个"快而可见"的完整系统**：

1. **复现经典管线**：公开数据集 + CSP + LDA，国际通行基线，方法成熟、工具链完善，可行性高；
2. **主打时效性**：以"端到端响应延迟"为第一指标做参数实验与优化，回答"运动想象解码能做到多快"；
3. **可视化传达**：用网页版 App 把解码结果变成人人可懂的交互（菜单切换/确认），让评委和同学"玩"到脑机接口。

### 1.4 意义
- 对课程：走完"数据 → 模型 → 系统 → 展示"的完整工程闭环，证据链完整；
- 对企业：提供一份有实测数据支撑的"在线解码时效性"参考（窗长如何选、延迟花在哪），并交付带标准接口、可供小游戏/轮椅调用的解码模块；
- 对团队：在能力边界内做出可现场演示、可量化评价的真实系统。

## 2. 相关工作与前期调研

- **公开数据集**：BCI Competition IV Dataset 2a（9 名被试、22 通道、4 类运动想象）是国际公认的标准评测集；PhysioNet eegmmidb（109 名被试、64 通道，含想象左右手握拳任务）免注册、工具链内置支持，适合开发期快速迭代。
- **经典方法**：共空间模式（CSP）是运动想象特征提取的标准方法，配合 LDA 等线性分类器在二分类任务上被广泛报道可达约 70–80% 准确率，且推理开销极小，天然适合在线场景。
- **已知现象**：数据集中存在个体差异显著的"BCI illiteracy"（部分被试信号难以解码），评测需如实报告被试选择与协议。
- **工具生态**：MNE-Python 提供上述数据集的下载与官方 CSP 解码示例；scikit-learn 提供 LDA 与交叉验证；Streamlit/Gradio 可快速构建网页 App。

## 3. 项目目标

### 3.1 总目标
复现并交付一个**低延迟、可视化**的运动想象在线解码系统：对回放 EEG 流进行实时解码，将"想象左手握紧 / 右手握紧"分别映射为**切换 / 确认**指令，驱动网页 App 完成菜单式交互，并以实验数据量化系统的时效性。

### 3.2 可量化指标

| 维度 | 指标 | 目标值 |
|---|---|---|
| 解码性能 | 二分类离线准确率（5 折交叉验证） | ≥ 70%（同时报告 Cohen's Kappa，目标 > 0.3） |
| | 留出测试集泛化准确率（未参与训练的数据） | ≥ 65%，与交叉验证差距 ≤ 10 个百分点 |
| **时效性（核心卖点）** | 单窗推理时间（滤波→CSP→LDA 出结果） | < 100 ms |
| | 界面指令更新频率 | ≥ 3 次/秒（滑动窗步长 ≤ 0.33 s） |
| | 推荐配置下端到端响应延迟（窗长+推理+渲染） | 实测并给出预算分解，推理+渲染部分 < 200 ms |
| 稳定性 | 连续回放演示 | ≥ 5 分钟无中断；稳定性测试 ≥ 30 分钟 |
| 过程证据 | Git 提交与实验记录 | 每周更新，里程碑打 tag |

### 3.3 预期成果
1. 解码模块（Python 包，标准指令接口，可供上层应用调用）；
2. 网页版 App 可视化演示系统（菜单交互：左手=切换、右手=确认）；
3. 时效性实验报告（窗长-准确率-延迟权衡曲线、端到端延迟预算分解）；
4. GitHub 仓库（代码 + 环境 + 实验记录 + 每周 tag）与 Demo Day 物料（海报、PPT、录屏）。

## 4. 技术路线

### 4.1 系统总体架构

```
公开 EEG 数据集（开发：PhysioNet eegmmidb / 评测：BCI IV 2a）
        │
        ▼
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│ ① 预处理      │→│ ② 特征提取    │→│ ③ 分类训练    │
│ 带通8–30Hz   │  │ CSP 空间滤波  │  │ LDA + 交叉验证│
│ 分段、去伪迹  │  │ (4分量)      │  │              │
└──────────────┘  └──────────────┘  └──────┬───────┘
                                            │ 训练完成，固化模型
        ┌───────────────────────────────────┼────────────────────┐
        ▼ (离线检验)                          ▼ (在线模拟)          
┌──────────────┐                    ┌──────────────────┐         
│ ④ 留出数据检验 │                    │ ⑤ 回放解码引擎     │         
│ 未见过数据测   │                    │ 滑窗伪实时回放     │         
│ 准确率/Kappa  │                    │ 每0.25–0.33s出一次  │         
└──────────────┘                    │ 判定+置信度        │         
                                    └────────┬─────────┘         
                                             ▼ 标准指令接口
                                    {"label": left/right/idle,
                                     "confidence": 0.0~1.0}
                                             │
                                             ▼
                                    ┌──────────────────┐
                                    │ ⑥ 网页版App       │
                                    │ 左手=切换选项      │
                                    │ 右手=确认选项      │
                                    │ 置信度不足=不动    │
                                    │ 实时概率条+波形    │
                                    └──────────────────┘
```

### 4.2 分步技术方案（对应我们的复现步骤）

**Step 1 开源数据获取**：开发期用 eegmmidb（MNE 一行代码下载，官方示例即基于它，跑通成本低）；指标评测对齐 BCI IV 2a（标准协议，结果可与文献比较）。仅取"想象左手 vs 右手"二分类试次。

**Step 2 预处理**：8–30 Hz 带通滤波（保留 μ/β 运动节律）；按事件标注截取想象时段数据段；剔除明显坏段/坏通道。输出滤波前后波形对比图作为证据。

**Step 3 训练 CSP + LDA**：CSP（4 个空间滤波分量）提取特征 → LDA 训练二分类器 → 5 折交叉验证评估，输出准确率、Kappa、混淆矩阵。

**Step 4 留出数据检验**：训练前预留一部分试次/被试数据**全程不参与训练**，仅在模型固化后测试一次，得到泛化性能，防止"背答案"。

**Step 5 模型固化**：保存训练好的滤波器与分类器参数（pickle/joblib），线上阶段只加载不重训。

**Step 6 回放检测（伪实时）**：将未见过数据按滑动窗口（窗长 1–2 s、步长 0.25–0.33 s）流式喂入，模拟在线采集；每窗输出判定与置信度；置信度低于阈值输出 `idle`（不动），配合滑动多数投票平滑，防止界面抖动。

**Step 7 网页 App 可视化**：用 Streamlit 或 Gradio 构建浏览器界面：菜单列表 + 高亮当前选项 + 实时左/右概率条 + 滚动脑电波形；左手指令=高亮下移（切换），右手指令=选中当前项（确认）。浏览器打开即像 App，手机/电脑均可演示。

### 4.3 时效性设计（核心卖点的技术支撑）

把"快"拆成可测的三段：**端到端延迟 ≈ 窗口积累时间 + 推理时间 + 通信渲染时间**。

| 实验/措施 | 内容 | 产出 |
|---|---|---|
| T1 窗长权衡实验 | 窗长 1.0 / 1.5 / 2.0 s × 准确率 × 响应速度 | "准确率-延迟"权衡曲线，给出推荐窗长及理由 |
| T2 推理计时 | `time` 实测单窗滤波+CSP+LDA 耗时（100 次取均值） | 证明推理 <100 ms，"慢的锅在攒数据不在算法" |
| T3 平滑与抖动权衡 | 投票窗口 2/3/4 次对稳定性的影响 | 稳定性与响应速度的平衡点 |
| T4 端到端实测 | 从数据进入窗口到界面高亮变化的全链路计时 | 延迟预算分解表（项目报告的核心图） |

### 4.4 关键技术选型

| 环节 | 选型 | 理由 |
|---|---|---|
| 语言 | Python 3.11 | EEG 生态最全，AI 辅助编程成熟 |
| EEG 处理 | MNE-Python | 数据集内置下载 + 官方 CSP 示例，复现起点 |
| 特征/分类 | CSP + LDA（scikit-learn） | 国际标准基线，推理快、可解释 |
| 在线模拟 | 自研滑窗回放引擎（<100 行） | 无需真实设备即可验证在线性能 |
| 网页 App | Streamlit（备选 Gradio） | 零基础 1 天可出界面，浏览器即 App |
| 协作 | GitHub + GitHub Desktop | 过程证据链载体 |

## 5. 可行性分析

1. **方法成熟**：CSP+LDA 是教科书级基线，MNE 官方提供端到端示例，复现路径明确；
2. **数据免费可得**：两个数据集均为公开研究数据，无伦理审查负担；
3. **不依赖硬件**：伪实时回放替代真机采集，规避设备与调试风险（真机接入留作与设备方联调的扩展项）；
4. **工作量适配**：核心管线可在官方示例上增量修改完成；网页 App 用 Streamlit 门槛低；时效性实验本质是"改参数重跑+计时"，与大一能力匹配；
5. **过程可控**：每周里程碑+证据链，风险可早暴露（见 §8）。

## 8. 风险与应对

| 风险 | 概率 | 应对 |
|---|---|---|
| 环境/包安装失败 | 高 | 统一 Anaconda + 固定 `environment.yml`；预留 M1 周专门装环境；兜底用 Colab |
| 准确率不达标 | 中 | 更换被试（BCI illiteracy 现象，如实报告被试选择协议）；调整频段与 CSP 分量数；负结果如实分析同样计入成果 |
| 端到端延迟偏大 | 中 | 用 T1 权衡曲线选甜点窗长；若 2 s 窗体验差，降到 1–1.5 s 并接受小幅准确率损失，用数据说明取舍 |
| 网页 App 实时刷新卡顿 | 中 | Streamlit 自动刷新+局部更新；兜底录制演示视频+键盘模拟指令模式 |
| 进度被其他课程挤占 | 高 | 砍项顺序：BCI IV 2a 双数据集 → T3 实验 → App 美化；保住"管线+留出检验+回放演示"底线 |
| 现场演示崩溃 | 低但致命 | 3 分钟录屏备份 + 键盘兜底模式 |
