## 4. 读取代码模板（可执行骨架，未下载数据）

### 4.1 MOABB 路径（主）
```python
# venv_m3（已装 moabb 1.7.2 / mne 1.13.2）；先 cd 到项目根再跑
import os, mne
os.environ["MNE_DATA"] = r"D:/校企合作项目/.deepworks/mne_data"   # 数据落 D 盘，不入库

from moabb.datasets import BNCI2014_004, Lee2019_MI
from moabb.paradigms import MotorImagery

# 契约 8 通道（顺序即语义）
CONTRACT_CH = ["C3", "Cz", "C4", "CP3", "CP4", "P3", "P4", "Oz"]

def load_subj127(dataset):
    """返回 pick 契约通道交集后的 epochs（X, y, metadata）。
    只取 left_hand/right_hand 两类；重采样到 250 Hz。"""
    paradigm = MotorImagery(events=["left_hand", "right_hand"], n_classes=2,
                            resample=250)          # MOABB 自带重采样（FFT/decimate）
    epochs = paradigm.get_data(dataset, subjects=[1, 2, 7], return_epochs=True)
    chs = [c for c in CONTRACT_CH if c in epochs.ch_names]   # 交集，不重排
    return epochs.copy().pick(chs), chs

# BCI IV 2b —— 命中 3/8（C3/Cz/C4）
# epochs_b, chs_b = load_subj127(BNCI2014_004())
# OpenBMI —— 命中 8/8
# epochs_o, chs_o = load_subj127(Lee2019_MI())
```

要点：
- `MotorImagery(resample=250)` 由 MOABB 内部完成 `1000 → 250 Hz`，无需手写重采样。
- `pick(chs)` 用**交集 + 原顺序取**，不凭空补通道、不重排（守住 AGENTS 红线 4）。
- `get_data` 首次运行会自动下载全部受试 → **这是"下载"动作，等团队拍板后再跑**。

## 5. 重采样路径

- **BCI IV 2b**：本身就是 **250 Hz**，与契约一致，**无需重采样**。
- **OpenBMI**：**1000 Hz** → 需降到 250 Hz。
  - 首选：`MotorImagery(resample=250)`（MOABB 内部处理）。
  - 手动等价实现（供理解/核对）：
    ```python
    raw = raw.copy().pick(CONTRACT_CH).filter(l_freq=8, h_freq=32, method="iir")
    raw = raw.resample(250)      # MNE FFT 抗混叠重采样；离线数据预处理可用
    epochs = mne.make_fixed_length_epochs(raw, duration=2.0)  # 或按事件对齐
    ```
  - ⚠️ 红线 2 只约束**在线解码链路**必须用因果 `sosfilt`；**离线数据预处理**重采样/滤波不受此限，但对外口径仍不准报裸准确率。
- 契约滑窗 2.0 s / 步长 0.5 s：在 250 Hz 上切 `[500 / 125 点]`（与 M3/M4 `.deepworks/venv_m3` 口径一致）。

## 6. 结论与建议（供 12/04 拍板）

1. **扩充第一顺位 = OpenBMI（Lee2019_MI）**：54 人、左右手二类、**契约 8 通道 8/8 全命中**、interval [0,4] s
   （trial 整 4 s，足够切 2.0 s 窗 × 多步），样本量最大，最贴合现有 8 通道契约。
2. **BCI IV 2b（BNCI2014_004）**：9 人但仅 3 EEG 通道（C3/Cz/C4），只能作**三通道左/右手泛化补充**，
   不能直接承接 8 通道契约；如需纳入需单列口径。
3. **注意类是 `BNCI2014_004` 不是 `BNCI2014_002`**（002 是 14 人 right_hand/feet 的另一个库）。
4. 数据落 `.deepworks/mne_data`（不入库）；**首次 get_data 触发下载，需团队确认联网后执行**（12/04 拍板 → 12/08 前出第一版证据）。
