## 4. D1–D2 跑通步骤（保姆级，全员）

> 命令在 **`bci-decoder/`** 目录下执行；PowerShell **不要用 `&&`**。
> 建议 Python **3.14.x**（与组长一致，最低 3.10）。**不要装上游 `pygame`**（无 3.14 wheel），`requirements.txt` 里已是 `pygame-ce`。

```powershell
# 0) 拿到最新代码（已克隆过的目录里）
git pull

# 1) 建虚拟环境、装依赖（websockets 与 pygame-ce 已在清单里，一次装全）
cd motion-imagination-decode-module\bci-decoder
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# 2) 测试全绿（解码端 17/17，游戏端 39/39）
python -m pytest
python -m pytest -q "game\tests"

# 3) 训练演示模型 + 在线解码自检（mock 源）
python scripts/bootstrap_demo.py --config configs/default.yaml
python -m bci_decoder.cli run --config configs/demo_online.yaml --chunks 200

# 4) 键盘版弹球（窗口能开、方向键能控）
python game\pong.py --input keyboard
```

**每步截图**，丢进 `docs/evidence/W9_1027/A1/`（命名 `A1_姓名_步骤.png`）。

**常见坑**：
- `No module named pytest` → 没激活 venv；或改用显式路径 `.venv\Scripts\python.exe -m pytest`
- 在仓库根跑 pytest → 会多收集 `docs/learning/` 的学习用例（29 个而不是 17 个），**先 `cd bci-decoder`**
- 游戏端测试必须显式传路径 `game\tests`（`pytest.ini` 不自动收它）

## 5. 红线（冲刺期最容易踩的）

1. **不报任何准确率数字**（评审演示稿、讲解词、录屏里都不许出现）；`mock`/`synth` 的交叉验证 100% 是必然结果，不是成绩。
2. **降级如实通报**：键盘版就是键盘版（C 级）、回放就是回放——现场说"这是键盘降级演示"不丢人，说成脑控实时才是事故。
3. 不改冻结项：输出 9 字段、通道顺序、滑窗 2.0 s / 步长 0.5 s、2 类 + `idle`。
4. 在线链路禁止 `filtfilt`。
5. 改代码必跑 `pytest`；证据**当天归档**，不攒到 D7。
