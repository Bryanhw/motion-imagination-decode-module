## X7：已完成的准备与后续接入备忘

1. **设备和环境**：演示机、Python版本、是否能装 `pylsl`、采集软件与驱动、谁能启动设备。先用独立环境评估，不改已跑通的 MVP 环境。
2. **真实数据交接**：采集流名和类型、实际采样率、原始单位、设备实际通道名与顺序、任务标签和事件时间。必须核对 C3、Cz、C4、CP3、CP4、P3、P4、Oz 的显式映射；缺失通道不补零或猜测。
3. **校准输入**：参考[校准流程](calibration_flow.md)，确认 `(n_channels, n_samples)` 连续数据及 `labels.npy` 的 trial 对应关系、分段起点和 `left/right` 语义。先确认数据格式和存放位置，再运行校准；不提交真人原始数据。
4. **自检证据**：范围确认且设备发布流后，先 `--list` 找到正确流，再跑 60 秒检查，记录发现的流、实际元数据、映射结果和报错。仅发现流不代表校准、解码或闭环通过。

在配置好依赖的 M4 环境中，从 `bci-decoder/` 运行：

```powershell
python scripts/lsl_selftest.py --list
python scripts/lsl_selftest.py --check 60
```

存在多个 EEG 流时，用 `--stream-name` 指定已确认的流名。没有设备可先用 `--from-npy` 做离线自检，结果标为离线，不能代替设备接入。团队 X7 已完成；本机检查见个人任务卡。RA1 在原受限机器跟进，真实采集闭环待 RA1 与设备。
