## §0 开场｜"意图 → 指令"这条链到底是什么

**讲稿说了什么**：把"想往左、想往右"翻译成游戏能用的指令。

**背后的原理**

直观版：脑电本身是几十微伏的电压波动，看不出"左/右"。要读出意图，得走一条流水线：

```
电极采集 → 滤波去噪 → 切时间窗 → 提特征 → 分类器判类 → 稳定化 → 消息 → 游戏
```

技术版（本项目实际链路）：

| 环节 | 实现 |
|---|---|
| 滤波 | 50 Hz 陷波 → 8–30 Hz 带通（Butterworth，4 阶，SOS）→ CAR 共平均参考 |
| 切窗 | 2.0 s 窗、0.5 s 步长（每 0.5 s 出一个判断） |
| 特征 | CSP 空间滤波 + log-方差（在线默认）／协方差切空间（评测对照） |
| 分类 | 标准化 + LDA |
| 稳定化 | EMA 平滑 → 连续 3 次一致 → 置信度 ≥0.6 才切换，否则 idle |
| 输出 | 固定字段 JSON：`label/label_id/confidence/probs/state/compute_ms/...` |

**被追问时**：这条链每一环都可单独验证，所以"游戏能动"和"分类准不准"是两件事。

## §1 两个问题｜"泛化"在脑机接口里指什么

**讲稿说了什么**：换成真实脑电还能不能识别？换时段、换人还在不在？

**背后的原理**

直观版：同一个人今天戴电极和明天戴，电极位置、皮肤阻抗、注意力都不一样，信号分布会漂。**模型在 A 天学会的规律，B 天不一定成立**——这就是"泛化"问题。

技术版，本项目测两种泛化：

| 类型 | 切分 | 问的问题 |
|---|---|---|
| 跨时段（cross-session） | 同一受试 `0train` 训练 → `1test` 测试 | 同一个人换个时段还能用吗 |
| 跨被试（cross-subject） | 留一受试：8 人训练、1 人测试，逐人轮换 | 新用户不校准能用吗 |

工程可靠性（消息能驱动、断流能停）与分类效果（Kappa）**是两条独立证据链**，不能互相替代。

**被追问时**：跨时段测"同一个人换天"，跨被试测"换个人"，两者难度不同，报告里分开写。

## §2 数据与划分｜为什么必须"训练/测试不同时段"

**讲稿说了什么**：公开数据、0train/1test、留一受试、22 通道 vs 8 通道。

**背后的原理**

直观版：如果拿同一段数据既教模型又考模型，等于考前泄题，分数必然虚高。所以训练和测试必须**时间上完全分开**。

技术版：

- 数据：BCI Competition IV 2a（BNCI2014-001），9 名受试，左右手运动想象。运动想象时，对侧运动皮层（C3/C4 附近）的 mu/beta 节律功率会下降（ERD），这是可分的生理基础。
- `0train` / `1test` 是两个不同 recording session，session 之间电极阻抗、注意力状态不同 → 天然构成"跨时段"测试。
- 22 通道 vs 8 通道：评测用原始 22 导；工程演示用团队冻结的 8 导配置（`C3, Cz, C4, CP3, CP4, P3, P4, Oz`）。**通道数不同 = 特征维度不同 = 模型不通用**，所以不能宣称"同一模型两套输入都行"。
- 通道顺序即语义：CSP 的空间滤波器按通道顺序训练，重排通道会让 `W @ x` 完全错乱——这是硬约束。

**被追问时**：评测用的是原始 22 导公开数据，演示是 8 导冻结配置，两套不能等同，报告里已分开写。

## §3 方法与口径｜CSP、LDA、黎曼切空间分别是什么

**讲稿说了什么**：CSP+LDA 与协方差/切空间+LDA 两条路线；比较方法必须同时比较划分。

**背后的原理**

**① CSP（共空间模式）**

直观版：不只看单个电极，而是找一组"空间配方"，让左手的信号在这组配方下方差很大、右手很小（反之亦然）。相当于给两类各配一副"放大镜"。

技术版：
1. 分别算两类窗口的平均协方差 `C0`、`C1`（带收缩正则）。
2. 解广义特征值问题 `C0 w = λ C1 w`。
3. 取 λ 最大的一批方向（类 0 方差占优）和 λ 最小的一批（类 1 方差占优），拼成空间滤波器 `W`。
4. 对每个窗口：`z = W x`，取 `log(var(z) / Σvar(z))` 作为特征（归一化 log-方差）。

注意：`W` 是**有状态**的，必须和模型一起保存/加载；在线只做一次矩阵乘，开销很小。

**② LDA（线性判别分析）**

直观版：在特征空间里画一条最优分界线，让两类离得尽量开、各自尽量聚。

技术版：先 `StandardScaler` 标准化，再找投影方向最大化"类间距离 / 类内散布"；输出后验概率。小样本、低延迟场景的强基线。

**③ 黎曼切空间（Riemannian tangent space）**

直观版：把每个时间窗的"通道间协方差矩阵"看成一个点，但这些点住在弯曲的空间里（正定矩阵流形），不能直接当向量用。做法是先算流形上的平均点，再把每个点"摊平"到这个平均点处的切平面上，变成普通向量，最后接 LDA。

技术版：协方差矩阵属于 SPD 流形；用黎曼均值作参考点，经矩阵对数映射（`logm`）投到切空间向量化。好处是**对通道间的线性混合不敏感**、跨被试更稳。代价是计算量比 CSP 大。

**④ 为什么"比较方法必须同时比较划分"**

直观版：四类混合时段的题比二类跨时段的题容易得多，拿简单题的分数去代表难题，就是耍流氓。

技术版：不同划分改变了先验、类别数和分布偏移，Kappa 不可跨划分直接比较。所以报告里口径 A（4 类、5 折混合）只作旁证，主讲口径 B（二类、严格跨时段）。

**被追问时**：CSP 找"空间配方"放大两类方差差，黎曼用协方差矩阵的几何距离；两条路线都接 LDA，比较时必须同一套划分。

## §4 结果｜Kappa、trial 级投票、ITR 到底怎么算

**讲稿说了什么**：trial 级平均 Kappa 0.466/0.481 达标；ITR 7.22/6.84；平均不代表每人。

**背后的原理**

**① Kappa 是什么、为什么不用准确率**

直观版：二分类瞎猜也有 50% 准确率。Kappa 把"瞎猜也能对的部分"扣掉，衡量"比瞎猜好多少"。

技术版：

```
κ = (p_o − p_e) / (1 − p_e)
```

二分类且两类均衡时 `p_e = 0.5`，于是 `κ = 2·p_o − 1`。
- 准确率 0.75 → Kappa 0.50
- 准确率 0.55 → Kappa 0.10（几乎等于瞎猜）

判据 0.3 来自 BCI 竞赛惯例，**不是"准确率 30%"**。

**② 窗口级 vs trial 级：为什么要 3 窗投票**

直观版：每 0.5 秒判一次，单次容易抖；把一个 trial 里 3 个窗口的判定投票（多数票），相当于"三个人投票"，更稳。

技术版：
- 窗口级：每个 2 s 窗单独算对错 → 样本多、噪声大、Kappa 偏低。
- trial 级：一个 trial 内取 3 个窗（起点 cue+0、+0.5、+1.0 s），各自分类后取**众数**（≥2/3 即定），再和该 trial 的真标签比。
- 两者的样本单位和随机基线不同，**Kappa 不能混用、不能相减当提升**。

注意区分（重要）：离线评测用的是"trial 内 3 窗众数（2/3 即可）"；游戏在线用的是更严格的"连续 3 次完全一致 + EMA + 0.6 门限"。**两者不是同一套规则**。

**③ ITR（信息传输率）**

直观版：不只是"准不准"，还要看"每分钟能可靠地传达几次意图"。

技术版（Wolpaw 二类公式，T = 2 s）：

```
ITR = [1 + p·log2(p) + (1−p)·log2(1−p)] / T × 60   (bits/min)
```

- 准确率越高，ITR 越大；准确率接近 0.5 时 ITR → 0。
- 例：p = 0.854、T = 2 s → 约 12.0 bits/min（对应 S08 CSP）。
- 报告主报"逐受试平均"（7.22/6.84），pooled 值（4.89/5.23）作脚注——**pooled 会把个体差异抹平，看起来更低**。

**④ 为什么"平均达标"不等于"人人达标"**

直观版：班里平均分及格，不代表每个同学都及格。

技术版：跨被试差异大（S05 Kappa≈+0.06、S02≈+0.14），平均被高分受试拉上去。所以对外只说平均值达标，被追问再给逐受试明细。

**被追问时**：Kappa 是扣掉机会水平后的一致性；trial 级是 3 窗投票后的单位；ITR 用 Wolpaw 公式按 2 秒窗换算。

## §5 离线 vs 伪在线｜因果滤波为什么是红线

**讲稿说了什么**：伪在线只用过去的信息，准确率差 <1pp，判据 5pp。

**背后的原理**

直观版：**离线可以"看未来"**（用整段数据正反各滤一遍，零相位、无延迟）；**在线不能**，只能看过去。如果在线也用"看未来"的滤波，等于作弊，实际设备上根本做不到。

技术版：
- 离线常用 `filtfilt`（零相位）：前后各滤一次，消除相位延迟，但需要整段数据 → 只能离线。
- 在线用 `sosfilt`（因果）：只依赖当前和过去样本，必然有相位延迟。
- 更关键的是 **state 跨块传递**：IIR 滤波器有内部状态；如果每 0.5 s 的 chunk 都从零状态开始滤，块边界会出现阶跃，一阶差分出现尖峰，频带功率抖动 → 解码输出乱跳。实际实现用 `sosfilt(..., zi=state)` 并把 `state` 存回，保证跨 chunk 连续。
- 伪在线评测：按块喂数据、只调 `transform`（不重训），模拟真实在线；与离线全量结果比较，差 <1pp 说明"离线结论在在线条件下仍成立"。
- 判据 <5pp 是工程约定（组长已拍板），不是理论定律。

**被追问时**：在线必须因果 + 传 state，否则块边界跳变；伪在线就是把这条链按块跑一遍再和离线比。

## §6 现场演示｜消息、idle 与安全降级

**讲稿说了什么**：left 前进、right 跳跃、idle 不发动作；停解码端看安全态；数据源逐段声明。

**背后的原理**

**① 消息契约**：输出字段冻结（`t_data/t_wall/label/label_id/confidence/probs/state/compute_ms/window_seconds`），`label_id == -1` 当且仅当 `label == "idle"`。游戏只认这些字段，所以换模型不改游戏。

**② 稳定化四道闸**（在线实际逻辑）：

| 闸门 | 参数 | 作用 |
|---|---|---|
| EMA 平滑 | α = 0.4 | 抑制单次概率抖动 |
| 连续一致 | 3 次 | 必须连续 3 次同类才切换 |
| 置信度门限 | 0.6 | 低于此值直接 idle |
| 保持上次输出 | — | 不满足条件时不动，避免来回跳 |

**③ idle 的本质**：不是"识别到静息"，而是"这次不发布动作"。触发条件包括：置信度不足、模型缺失、显式安全状态。

**④ 为什么未训练时一定是 idle（红线）**：未训练时分类器输出均匀概率（0.5/0.5），置信度 0.5 < 门限 0.6 → 稳定化直接给 idle。所以"模型缺失→idle"不是靠人守纪律，而是链路设计上就成立。

**⑤ 安全降级**：只停解码端、游戏不关 → 看角色停止持续前进、空中能落地；重启后"连接恢复"与"有效动作恢复"是两个时刻（还要重新攒窗、过稳定化）。演示要如实呈现这个时间差。

**被追问时**：idle 是"不发布动作"的安全状态；未训练的均匀概率天然低于 0.6 门限，所以不可能发出随机左右。

## §7 改进验证｜为什么欧氏对齐"没用"、FBCSP 反而更差

**讲稿说了什么**：四条路线都试了，前三条与基线逐位一致，FBCSP 更差。

**背后的原理**

**① 欧氏对齐（EA）做了什么**

直观版：先把每个 session 的信号"调音"到同一响度，再比较。

技术版：算参考平均协方差 `R_ref`，用 `W = R_ref^(-1/2)` 白化信号，使各 session 的协方差都接近单位阵。无监督、不需要标签。

**② 为什么 CSP/Riemann 对它不敏感**

- CSP 特征是 `log(var(Wx)/Σvar(Wx))`——对信号做满秩线性变换 `A` 后，CSP 会学到等价的 `W' = W A^(-1)`，**归一化 log-方差比值不变**。
- 黎曼切空间基于协方差的几何结构，对同类满秩变换同样不变。
- 再加上本项目预处理后信号已接近谱白/各向同性，白化≈恒等 → 实测与基线**逐位一致**（不是 bug，是数学必然）。
- 结论：EA 的收益主要体现在**跨被试/跨 session 分布差异大**的场景；在本项目的"单被试跨天 + 已强预处理"设定下，没有可挖的空间。

**③ FBCSP 为什么更差**

FBCSP = 分多个子带（4–8、8–12、12–30 Hz）各做 CSP，再拼接特征。
- 子带越多，每带可用样本越少，CSP 的协方差估计越不稳；
- 本项目 CSP 在特征值近重根时对数值顺序敏感（特征基不唯一），子带融合放大了这种不稳定；
- 实测平均 Kappa 0.403 < 0.466，且 S02/S04/S05 明显恶化。
- 结论：不是"子带没用"，而是**在当前样本量与数值条件下不划算**；要做需逐受试选带宽 + 交叉验证。

**④ 数值脆弱性（CSP 的真实短板）**

CSP 的广义特征分解在两类协方差接近时会出现"特征值重根"，特征向量不唯一，BLAS 实现不同就可能选出不同的基 → 同一数据的 Kappa 会波动。**处置**：绝对指标以可复现的 ITR 档为准；伪在线只作相对一致性判据。

**被追问时**：EA 是满秩线性变换，CSP/黎曼对它是不变的，所以"没用"是数学结果；FBCSP 是样本量和数值稳定性问题，不是方向错误。

## §8 结论｜"个人校准"为什么是下一步

**讲稿说了什么**：缺口是无校准跨被试泛化和真实模型现场集成。

**背后的原理**

- 每个受试的脑电"指纹"不同（头型、皮层折叠、电极阻抗），跨被试直接套用模型，分布偏移大 → LOO 实测 Kappa 0.191/0.200，接近随机。
- 解决办法是**个人校准**：用该受试少量数据做对齐/微调（EA、协方差对齐、少样本迁移），把分布拉回训练分布附近。
- 现场集成是另一条线：演示链路的模型、通道、延时、稳定性要单独验证，不能用离线指标替代。

**被追问时**：无校准跨被试接近随机是公开数据上的常见结果，所以产品化必须先做个人校准。

## §9 收尾问卷｜为什么主观问卷不算"准确率证据"

**讲稿说了什么**：问卷收主观手感，和数据是两套证据。

**背后的原理**

- 客观证据：Kappa、ITR、一致性——基于标注真值，可复现。
- 主观证据：可用性、延迟感、负荷、意愿——基于量表，反映体验，不能当准确率。
- 两者混用会误导（比如"85% 的人觉得好用"≠"85% 准确率"），所以问卷里**刻意不设准确率题**。

**被追问时**：问卷测体验，报告测性能，两者互补但不互相替代。

| 黎曼切空间 | 协方差矩阵投到切平面变向量，再接 LDA |

| trial 级投票 | 一个 trial 内 3 窗取众数（≥2/3） |
| ITR | Wolpaw 公式，按 2 s 窗换算 bits/min |
| 因果滤波 | 只用过去 + 跨 chunk 传 state，禁 filtfilt |
| 伪在线 | 按块喂数据、不重训，模拟真实在线 |
| 稳定化 | EMA α=0.4 + 连续 3 次一致 + 置信度 0.6 |
| idle | 不发布动作的安全状态（非"识别静息"） |
| EA | 白化到单位协方差；对 CSP/黎曼是不变变换 |
| FBCSP | 多子带 CSP 拼接；样本少时更不稳 |
