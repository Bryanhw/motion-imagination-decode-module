## 0. 前置提醒（先看清，别返工）

## 7. 必须达到的"数字结果"

1. **单次计算耗时 p95 < 50ms**（预期 p50 约 3.1ms、p95 约 4.7ms）；
2. **启动到出结果 ≤3 分钟**；
3. **连续运行 1h 无崩溃、无明显内存泄漏**；
4. **4/4 成员跑通全流程**（每人 1 份记录）；
5. **游戏端实际订阅到 WebSocket 消息并驱动画面**；
6. **弱信号/未训练/不可信时恒输出 `idle`，绝不随机左右**（有测试用例 + 演示素材）；
7. **3 名同学内测反馈已收集并整理归档**。

## 8. 口径红线（演示当天必须照说）

1. **不报任何准确率数字**——演示稿、讲解词、截图都不许出现。
2. **降级如实通报**：键盘版是 C 级降级，现场明说"这是键盘降级演示"，不丢人；说成实时脑控才是事故。
3. **不夸大**：现场翻车就照预案降级，不硬撑。
4. **冻结项不动**：输出 9 字段、通道顺序、滑窗 2.0s/步长 0.5s、2 类 + idle。
