## 1. 数据与处理口径（两个脚本一致）

- 数据：BNCI2014-001（BCI IV 2a）；0train/1test 严格跨 session。
- 窗：cue 起 2.0 s / 0.5 s，每 trial 3 窗（样本 250/375/500，4 s epoch 内）。
- 预处理：notch 50 Hz + bandpass 8-30 Hz（4 阶）+ CAR（对齐 `configs/demo_online.yaml`）。
- 特征/分类：csp(log,4)+LDA 与 riemann(Covariances(lwf)+TangentSpace)+LDA；LDA(lsqr, shrinkage=auto)。
- 脚本：`bci-decoder/scripts/m3/pseudo_online_vs_offline.py`（伪在线，支持 --binary）、`bci-decoder/scripts/m3/loo_cross_subject.py`（LOO）；venv_m3 运行。

## 3. Kappa 双口径并列（已决策 2026-11-03）

**口径 A · 首轮内部（2026-10-24）4 类 + 5-fold 混合 session**：riemann **0.438**（>0.3 达标）、csp 0.242、fbcsp 0.294（代价不可接受）、mdm 0.143。作为「研究性基线上限」。注意：5-fold 混合 session 存在**同受试两 session 间近似泄漏、偏高**。

**口径 B · 二类 + 严格跨 session（0train→1test）平均 Kappa（trial 级 3 窗投票）**：csp **0.466** / riemann **0.481** → **> 0.3 达标**（权威来源：`itr_report.py`，两次全量运行逐位一致）。

> **【2026-11-05 勘误】** 本稿初稿曾写 csp 0.198 / riemann 0.046 —— 该数字来自伪在线脚本全量跑时被 CSP 数值翻转污染的日志（S01/S02/S04/S07/S08 等受试特征基翻转，绝对 Kappa 不可信）。根因：CSP 特征值近重根时特征向量对 BLAS 浮点运算顺序敏感（已排除 seed/线程/对象复用/数据差异），属 CSP 数值脆弱性。**修正后**：绝对 Kappa/acc 统一以 `itr_report.py`（trial 级投票、两次运行逐位可复现）为准；伪在线脚本仅用于 §2「一致性判据」（相对量，跨 5 次全量运行稳定：Δ+0.13/+0.15pp、一致率 0.9663/0.9583）。详见正式报告 `docs/M3_基线与伪在线报告_草稿.md` §2/§4。

**决定**：双口径并列、如实标注——0.438 为研究性基线（混合 session、4 类），跨 session 二类（**trial 级 3 窗投票**）0.466/0.481 为严格泛化口径、**已达标 > 0.3**；**窗口级（不投票）Kappa 仍偏低**，列入下一步改进目标（在线自正则对齐、逐受试带宽、更稳特征）。两口径不可混用。
