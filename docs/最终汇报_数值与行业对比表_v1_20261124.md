## 二、要讲的 3 条"不足"（必讲，红线：不藏短）

1. **免校准跨被试 ≈ 随机（Kappa 0.19）**：这与领域共识一致——无校准跨被试本来就难。所以产品必须走"个人校准"（这也是 DS 叙事主线）。
2. **窗口级 Kappa 0.36 偏低**：是保守口径（每 0.5s 一个窗，噪声大）；trial 级三窗投票后 0.466/0.481。**对外讲时说明取保守口径**，避免被误认为低了就不好。
3. **端到端响应 ≤3s，瓶颈在生理窗口**：2 秒攒窗是物理约束（脑电节律需要用够时长才稳），不是我们算法慢——这是"脑电控制"类系统固有的延迟来源，可以把它定位为"当前生理约束下的合理值"。
4. （附加，视时间）**个体差异 / BCI illiteracy**：校准后仍有弱受试（S02/S05），正接"试玩门"设计。

## 三、口径备注（被追问时对照讲）

- 数字口径来源 = `agent_docs/testing.md` 唯一允许的公开数据集：**BCI IV 2a**；个人校准 = D1（同数据）。
- **不报裸准确率**的原因：二分类瞎猜也有 50%，Kappa 扣掉机会水平。0.3 是竞赛惯例的"有意义判据"，不是"准确率 30%"。
- 通道口径：评测原始 22 导（M3）；工程演示 8 导冻结配置（医疗 C3 Cz C4 CP3 CP4 P3 P4 Oz）。**两者不能混用**，对外分开写。
- trial 级 vs 窗口级：样本单位不同，Kappa 不能相减当"提升"。
