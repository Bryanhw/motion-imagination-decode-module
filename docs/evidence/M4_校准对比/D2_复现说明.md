# D2｜公开脑电个人校准回放

独立测试目录：D:\项目16\m4-t8-20261113\bci-decoder。使用该目录新建的 .venv。
数据为 PhysioNet EEGMMIDB S001；R04/R08 校准（左16、右14），R12 完整留出回放。按标注提取 cue 后 0.5–2.5 秒；选 C3/Cz/C4/CP3/CP4/P3/P4/Oz，统一 250 Hz、微伏。CSP/LDA 均来自个人校准数据，未复用合成 OOD 模型（本配置禁用 OOD，保留置信度与稳定化）。不报告分类准确率。

## 复现
在 bci-decoder 下安装 requirements.txt 及可选 mne、imageio-ffmpeg。准备脚本放入 artifacts 后执行：
    .\.venv\Scripts\python.exe artifacts/d2_prepare.py
脚本默认生成 8765 配置；本机 8765 被占用，录制时将 replay.yaml 的 ws_port 改为 18765。

终端1：
    .\.venv\Scripts\python.exe -u -m bci_decoder.cli run --config artifacts/d2_s001/replay.yaml
终端2：
    .\.venv\Scripts\python.exe -m game.platformer.main --mode ws --ws-url ws://127.0.0.1:18765
游戏按 Enter，不按 W/D。录屏注明「公开 EEG 数据回放｜个人校准模型｜非现场采集」。

按确认的 D2 要求，重启解码器加载个人配置即可，无需不停机切换。预检视频 55 秒。自动预检视频由实际 pygame 游戏画面和同次解码输出合成，正式联调与录屏由黄凯森负责。原始及转换 EEG 不随视频交付。
