# A10 断线重连演练（工程自检级，2026-10-21）

> 对应 `docs/M2冲刺作战清单.md` 缺口 3 的 A10「断线重连演练」部分。
> 位置：完整证据 JSON `A10_断线重连演练.json`（同目录）；原始脚本 `.deepworks/tmp/verify_a10_reconnect.py`（非交付物）。
> **场景**：真实解码器（合成源，仅工程自检）→ ws://127.0.0.1:8765 → 游戏端 `pong --input ws --headless`。

## 1. 结论（一句话）

连接中杀掉解码器进程 → 游戏**不崩**、进「信号丢失」安全态（只发 `idle`，不编造方向）→ 重启解码器 → **自动重连（connects=2）续收消息**，全程 **0 畸形、无 Traceback、跑满 3600 帧退出码 0**。

## 2. 环境

| 项 | 值 |
|---|---|
| OS / Shell | Windows（PowerShell 5.1） |
| Python | 3.14.7（`bci-decoder/.venv`） |
| 数据来源 | `configs/demo_online.yaml` 合成源（**仅工程自检，红线 5**） |
| 显示 | headless（SDL dummy） |
| 关键参数 | `backoff_min/max=0.5/5.0s`、`stale_timeout=3.0s`（默认） |

## 3. 时序与结果

| 时刻 | 动作 | 结果 |
|---|---|---|
| 0s | 解码器启动，ws 监听 8765 | OK |
| ~2.5s | 游戏 `--input ws --headless --max-frames 3600` 启动 | 连接成功 |
| ~8.5s | **杀掉解码器进程**（模拟崩溃/掉电） | 游戏不崩 |
| ~8.5–22.5s | 游戏进入「信号丢失」安全态，`stale_dropped=83`，`notes_seen.信号丢失=1`，只产生 `idle` 指令 | 安全态有效 |
| ~22.5s | **重启解码器** | — |
| ~26s | 游戏**自动重连续收**剩余帧 | `connects=2`，`received=11251` 总计 |
| 104.1s | 3600 帧跑满，退出码 0 | 全程无 Traceback |

## 4. 报告关键字段（`bci-pong-report/1`）

```
connects = 2            # 首次 1 次 + 重启后自动重连 1 次
received = 11251        # 总收消息（两段相加）
malformed = 0           # 畸形消息 0
stale_dropped = 83      # 断线期间超时回安全态的丢弃
consistency_warnings = 0
labels_seen = idle/right/left（含安全态 idle 1022 条）
无任何 acc/accuracy/准确率/正确率 字段  # 红线 1/6
```

## 5. 复现命令（两个终端 + 中途杀/重启）

```powershell
cd bci-decoder
# 终端 1
& .venv\Scripts\python.exe -m bci_decoder.cli run --config configs/demo_online.yaml --outputs websocket
# 终端 2
& .venv\Scripts\python.exe game\pong.py --input ws --headless --max-frames 3600 --report artifacts\pong_report_a10_reconnect.json
# 中途（任意时刻）杀掉终端 1 的 python 进程；等几秒再重启终端 1；观察终端 2 自动续上。
```
