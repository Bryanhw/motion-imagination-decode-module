# A8 现场演示 · 白话版操作说明

> 这份是给"没参与过联调、第一次上台"的同学看的。术语都换成了大白话，照着做就行。
> 配套正式版：`A8_现场执行手册_20261024.md`（含判据、归档细节）；判据来源：`agent_docs/testing.md` §5。
> **一句话目标**：演两遍游戏——先用键盘玩，再用"电脑判断左右"来玩；能玩、录下来、打勾，A8 就过了。

---

## 零、先明白我们在演什么

- **第一场（键盘版）**：证明**游戏本身是好的**——能走、能跳、能进关。
- **第二场（解码版）**：证明**"电脑判断左右"能真的带动角色**——判断结果通过一条消息管道传给游戏。
- **第三场（断线）**：证明**系统稳**——把"大脑"关掉，游戏不崩、不乱动，重开能自己连回来。

三个"黑窗口"就是命令提示符（PowerShell）。所有命令都在 `D:\校企合作项目\bci-decoder` 这个文件夹里敲。

---

## 一、上台前 10 分钟（5 件事）

| 步骤 | 做什么 | 怎么确认做好了 |
|---|---|---|
| 1 | **只开一台电脑**，别几台混着演 | 记住电脑名，写在纸上 |
| 2 | 打开命令窗口，进到项目文件夹：`cd D:\校企合作项目\bci-decoder` | 提示符前面显示这个路径 |
| 3 | **关掉所有旧的命令窗口和游戏窗口** | 任务栏里没有残留的黑色窗口 |
| 4 | **关掉系统代理**（设置 → 网络和 Internet → 代理 → 全部关） | 开关都是"关" |
| 5 | **开录屏**，把"命令窗口 + 游戏窗口"放同一个画面里 | 点开始录制，画面里有终端文字 |

> 为什么第 3 步重要：旧窗口会占着"端口"（相当于占着门牌号），新的就连不上。

## 二、第一场：键盘版（约 4 分钟）

### 操作步骤

1. 在命令窗口里敲（复制粘贴即可）：
   ```
   .venv\Scripts\python.exe -m game.platformer.main --mode keyboard
   ```
2. 等 1~3 秒，会弹出一个游戏窗口。
3. 按 **回车（Enter）** 开始。
4. 按住 **W**，角色往前走。
5. 快撞到障碍时，**点一下 D**（点一下就行，别长按）。
6. 吃到金币、走到关卡终点。
7. 按 **R** 重开一次（证明重开正常）。
8. 按 **Esc** 退出，回到命令窗口，**不该出现红色报错**。

### 讲解的人这时说

> "这是键盘模拟，先证明游戏本身、关卡、界面都是好的。下一步我们换成电脑判断的指令来玩。"

### 大家要盯的 4 件事

- [ ] 能往前走
- [ ] 能跳过障碍
- [ ] 能进下一关
- [ ] 退出后命令窗口没有报错

## 三、第二场：解码版（约 8 分钟，需要两个命令窗口）

先理解两个窗口的分工：

- **左边窗口 = "大脑"**：负责判断"左 / 右 / 不知道"，并把结果喊出去。
- **右边窗口 = "游戏"**：负责听，听到"左"就往左走，听到"右"就往右走，听到"不知道"就停着。

### 操作步骤

1. **开左边窗口**（先开它，后开游戏）：
   ```
   .venv\Scripts\python.exe -m bci_decoder.cli run --config configs\demo_game_ws.yaml
   ```
   它会开始一行一行打印东西，比如 `idle`、`left`、`right`。
   > ⏳ **这一步要等 10–15 秒**（本机实测 13.4 秒才就绪，因为它要先启动 Python 再加载模型）。**看到它开始打印 `idle` 了，再做第 2 步**；没打印就再等几秒，别急着重开。
2. **开右边窗口**：
   ```
   .venv\Scripts\python.exe -m game.platformer.main --mode ws --ws-url ws://127.0.0.1:8765 --timeout 1.5
   ```
3. 等游戏窗口弹出，看右上角/角落应该显示 **"已连接"**（或 running）。
4. 按 **回车** 开始。
5. **等约 2 秒**（第一个判断要攒够 2 秒数据，慢是正常的）。
6. 观察角色：它会开始**自己往左、往右走**（演示信号每 4 秒换一次方向）。
7. 观察角色"不知道"的时候：**应该停着不动**，不会乱跑。
8. 观察能正常越过障碍、吃金币。
9. 看两个窗口都没有红色报错、游戏没闪退。

### 讲解的人这时必须说（红线）

> "现在用的是**合成演示信号**，只是验证『判断结果能带动游戏』这条链路，**不是真人脑控，也不代表准确率**。"

### 大家要盯的 4 件事

- [ ] 游戏显示"已连接"
- [ ] 角色会自己左右走
- [ ] "不知道"（idle）的时候角色**真的停住**
- [ ] 全程不崩溃、不闪退

## 四、第三场：故意"拔线"（约 2 分钟）

这是在观众面前表演"系统很稳"：

1. 到**左边窗口**，按 **Ctrl + C**（等于把"大脑"关掉）。
2. 指着游戏说：**"看，它没有崩，只是停住了。"**
3. 确认角色停住不动、屏幕没有报错弹窗。
4. 把左边窗口那条命令**重新敲一遍、回车**。
5. 游戏会**在 1 秒内自己连回来**，角色继续动。

### 大家要盯的 3 件事

- [ ] 关掉"大脑"后游戏不崩
- [ ] 角色变成停住（不再乱走）
- [ ] 重开"大脑"后自动连上

## 六、怎么算"通过"

**四个硬要求全满足才算过**：

1. ✅ 键盘版能玩（能走、能跳、能进关、退出不报错）
2. ✅ 解码版能玩（连上了、角色会左右走、idle 时停住）
3. ✅ 断线不崩、能自动重连
4. ✅ 全程录屏，并且**每场都如实说明了数据来源**

> 只要有一项没做到，就**先别打"验收通过"的勾**，回头补演或补录。

## 七、翻车救场表（放在手边）

| 出了什么问题 | 现场怎么说 / 怎么做 |
|---|---|
| 游戏一直显示"连接中" | **先等 15 秒**（解码器冷启动需 13 s）；还不连就"稍等，我换一个干净的窗口重开" → 关掉所有旧窗口，先开左边、再开右边 |
| 连上了但角色不动 | 看左边窗口有没有在打印 → 没有就重开左边；有就再等 3 秒 |
| 按 D 就崩溃 | "这台是旧版游戏文件，我换成正式版" → 实在不行只演走路和跳跃，D 先不按 |
| 中文显示成方块 | "字体小问题，不影响功能" → 能修就修，别在台上折腾超过 1 分钟 |
| 开场 2 秒没反应 | "正常，约两秒出第一个判断" → **别慌、别重复按键** |
| 观众问"准确率多少" | "准确率要等 11 月正式评测，今天演示的是通路" |
