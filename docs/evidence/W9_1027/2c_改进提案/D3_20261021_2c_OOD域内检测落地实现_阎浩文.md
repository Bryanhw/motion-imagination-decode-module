## 3. 机制与阈值实况

- 在线判据（任一命中即 OOD → idle）：
  1. 马氏距离 `D²=(x-μ)ᵀΣ⁻¹(x-μ)`，阈值 `τ = max(χ²_{d,0.99}, 训练集经验 p99) × score_scale`；
  2. 信号强度下限（`strength_floor_enabled=true`）：强度 < 训练集 p5 → OOD（抓伪通道全零 / 近零输入——CSP 归一化抹掉绝对功率，马氏未必敏感）。
- 强度口径（训练/在线严格同源）：跨通道 RMS = `sqrt(mean(var(x, axis=1)))`；bootstrap 训练侧与 `core._window_strength` 同实现。
- 实测标定（demo_weak 训练，n_trials=80，seed 0）：
  | 量 | 值 |
  |---|---|
  | τ_χ²（χ²_{4,0.99}） | 13.2767 |
  | τ_emp_p99（训练集经验） | 12.3502 |
  | τ_final = max(·)×scale(1.0) | 13.2767 |
  | strength_floor（训练集强度 p5） | ≈ 3.21 µV |
- 产物：`artifacts/ood.joblib`（不入库），与 `demo_csp.joblib` / `demo_lda.joblib` 同批 `bootstrap_demo.py --config configs/demo_weak.yaml` 训出；**OODDetector 内部保存特征维度 d，加载期维度不匹配 → 告警降级**。
