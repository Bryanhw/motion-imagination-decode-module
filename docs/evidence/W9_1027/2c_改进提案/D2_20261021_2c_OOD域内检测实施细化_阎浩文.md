## 0. 一句话结论

给在线链路加一个**域内检测（OOD Detector）**：在“特征 → 分类”之间判定当前特征是否落在训练分布内，
域外（噪声、弱信号、增益漂移、伪通道干扰）**直接走 idle**，与现有 `min_confidence` 门限正交叠加。
走配置开关（默认关、灰度开），随模型产物发布，不改冻结契约。

## 1. 代码级根因（已核对源码）

| 环节 | 源码位置 | 行为 | 对 OOD 的影响 |
|---|---|---|---|
| CSP 特征 | `pipeline/features.py` L138–149 | `log(var / var.sum())` —— **归一化 log-方差**，绝对功率被抹掉 | 纯噪声与低 SNR 信号在特征空间落点相近，强度信息丢失 |
| LDA | `pipeline/classifier.py` L46–47 | `predict_proba` 把线性得分 softmax 到近 0/1 | 分布外特征仍被武断分到一侧，概率虚高（≈1.0） |
| 后处理 | `pipeline/postprocess.py` L53–58 | 仅当 `argmax 概率 < min_confidence` 才 idle | 挡不住“单类虚高”；`min_confidence=0.6` 形同虚设 |
| 决策循环 | `bci_decoder/core.py` L69–72 | `feat → predict_proba → stabilizer.update` | 无任何“输入是否在训练域”的判定 |

**结论**：当前链路是“开环信任”——只要 LDA 有分类面，任何输入都能拿到高置信指令。
与红线“置信度不足 → idle”的冲突，缺的不是置信度标定，而是**对输入来源可信度的判定**。

## 2. 目标与验收（内部工程口径，不对外报准确率）

1. **OOD 模拟集上 idle 占比 ≥ 95%**（噪声 / 弱信号 / 增益漂移 / 同相信号各形态），不再输出 right/left；
2. **训练分布样本不误杀**：`demo_online` / `demo_replay_switch` 的真实决策流回归不退化（左右按预期交替、边界短暂 idle）；
3. **不破坏既有口径**：`bci-decoder` 下 `python -m pytest` **22 项全绿**（新增用例另计，不合并进旧计数表述）；
4. **不触碰冻结项**：窗口 / 步长 / 类别数 / 通道顺序 / 9 字段契约，一处不动；
5. **延迟预算**：单窗口新增计算 **≤ +1 ms**（马氏距离在线成本 O(d²)，d=4 特征，实测应 <0.5ms）。

## 3. 方案：域内检测（主：马氏距离；辅：信号强度下限）

在 D1 基础上收敛，主判据选用**马氏距离（Mahalanobis）**，不引入额外监督、无训练态超参：

    D²(x) = (x-μ)ᵀ Σ⁻¹ (x-μ),   x ∈ R^d（d=4，CSP 特征）

- μ, Σ：训练期收集全部合法窗口的 CSP 特征后计算的均值与协方差（**与 CSP 一起随模型入库，不重训即可用**）；
- 阈值：x 的 D² 超过阈值 τ → 域外 → idle；
- τ 取两路取较大：① 卡方分位 χ²_{d,0.99} ≈ 13.28（高斯假设）；② 训练集经验 p99(D²_train)，并预留调节系数（默认 1.0，可配 `score_scale`）。

**为何不选**（对照 D1，补充分析）：
- OneClassSVM：rbf 核带宽 ν 需要额外标定，在线 O(d²) 同样成本，增益不明确；
- kNN 距离：在线需遍历训练集，延迟不可控；
- 概率校准（Platt/Isotonic）：只拉平“置信 vs 正确率”，不改变 OOD 整体被高置信判单侧的分布，治标不治本；
- 纯提高 `min_confidence`：2c 失败正是单类虚高，提门限只会更难触发。

**辅助判据（低成本、可选开关）**：信号强度下限。
由预处理后的窗口在带内总功率下限判定（训练期分布取 p5），低于下限（如整段近直流/近零输入）直接 idle。
意图：抓住“伪通道全零 / 设备未接好”这类马氏距离未必敏感的极端形态。作为 `strength_floor_enabled` 独立开关。

## 4. 落地设计

### 4.1 新增模块 `bci_decoder/pipeline/ood.py`

```python
@dataclass
class OODConfig:                      # 并入 config.py：PostprocessConfig 之后新增块
    enabled: bool = False             # 总开关（默认关，灰度开）
    method: str = "mahalanobis"       # mahalanobis | none
    chi2_quantile: float = 0.99       # 卡方分位阈值参考
    score_scale: float = 1.0          # 阈值系数（灰调试用）
    strength_floor_enabled: bool = False
    strength_floor_p5: float | None = None   # 训练期标定，随模型产物保存

    def fit(self, feats: np.ndarray, strength: np.ndarray | None) -> "OODDetector":
        # 训练期调用一次：算 mean / cov(inv) / 经验 p99 / 强度 p5
        # 存 μ, Σ_inv, tau_chi2, tau_emp, strength_floor
    def is_outside(self, feat: np.ndarray, strength: float | None) -> bool:
        # 在线：D2 > tau → True（OOD）；强度 < floor → True
    def save(self, path: str) -> None: ...   # joblib 序列化
    def load(cls, path: str) -> "OODDetector": ...
```

- **保存位置**：随模型产物，如 `artifacts/ood.joblib`（`artifacts/` 不入库，纪律不变）。
- **接入 `core.py`**：`push()` 循环中（L70 之后、L71 之前）插入：

```python
feat = self.features.transform(window)
strength = self._window_strength(clean_data_last)   # 仅 strength_floor 开启时计算
if self.ood is not None and self.ood.is_outside(feat, strength):
    probs = np.asarray([0.5, 0.5])        # 均匀概率 → stabilizer 自然输出 idle
else:
    probs = self.classifier.predict_proba(feat)
```

- **为什么把 OOD 映射成均匀概率**：复用 stabilizer 现有平滑 + 投票 + 门限逻辑，**输出字段、idle 语义、label_id=-1 全部不变**（契约零改动），且天然获得抗抖动（连续多片一致才固化）。
- **强度计算**：仅 `strength_floor_enabled=True` 时，取最近窗口的带内总功率标量；训练/在线同口径。
