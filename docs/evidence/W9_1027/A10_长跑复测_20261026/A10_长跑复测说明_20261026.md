## 3. 判据修正说明（重要）

首版复测脚本用 `|drift| ≤ 50`（绝对值），本次实测为 **−49.8 MB**，会擦边通过。但负漂移意味着**内存被 GC 回收**，不是泄漏，用绝对值判据在语义上是错的。已改为**单边上界**：`drift ≤ +50 MB`（只惩罚上涨）。按修正口径，本次结果更宽裕地通过。

内存曲线特征（见 `A10_60min_rss_20261026.csv`）：前 50 min 稳定在 **121–123 MB**，第 50–60 min 回落到 **~78 MB**，随后持平。这是一次正常的对象回收，不是"内存抖动"——handles 全程 232 附近（−10），线程数不变。

## 6. 已知限制

- 本次配置 **OOD 开启**（马氏距离 + 强度下限），比 2026-10-21 首轮 A10（`demo_soak.yaml`，无 OOD 段）**更严苛**；结论方向一致，但严格口径下两者不是同一配置，若需逐项对齐，可用 `configs\demo_soak.yaml` 再跑一次。
- 单机单实例，未覆盖多进程/GPU/网络并发场景。
- `mock` 源不产生真实 EEG 的幅值/噪声波动，内存行为可能与真实采集不同；真实采集下的长跑须在里程碑④（LSL 接入后）重做。
- 采样间隔 60 s，可能错过亚分钟级尖峰；峰值判据以采样点为准。
