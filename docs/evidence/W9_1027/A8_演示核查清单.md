## 2. 现场流程（每步打勾，异常走 §4 故障预案）

### 键盘版（判据①）
- [ ] 启动游戏：`python -m game.platformer.main --mode keyboard`（游戏根 `bci-decoder/` 下）
- [ ] Enter 开始游戏；W/D 移动、D 跳跃（如按 D 崩溃 → 立即停，属回归问题，先断 `repeat` 已修版确认）
- [ ] 角色正常行走、越障、进入下一关；HUD 正常显示（中文不豆腐块）
- [ ] 退出无崩溃（按 D 到 PowerShell 的旧崩溃已在修复版处理）

### 解码版（判据②，WS 驱动）
- [ ] 终端 1：`python -m bci_decoder.cli run --config configs/demo_online.yaml --outputs websocket`（可改用 `--config configs/demo_game_ws.yaml` 的 mock 自检链路）
- [ ] 终端 2：`python -m game.platformer.main --mode ws --ws-url ws://127.0.0.1:8765`
- [ ] 游戏右上连接状态显示「已连接 / running」；无连接时安全回退 NONE（灰置、不输入指令）
- [ ] 角色随 left/right 决策位移、随 idle 停住；`label_id == -1 ⇔ label == "idle"` 时无随机左右
- [ ] **断线演练**：杀解码器 → 游戏不崩、进「信号丢失」安全态、只发 idle；重启解码器 → 自动重连续收（对应 A10 演练已定性通过）

## 4. 故障预案（按优先级）

| 症状 | 处置 |
|---|---|
| 游戏「莫名连不上」解码器 | 先查端口占用（`netstat -ano`）、关闭系统代理后重试；仍不行用 `port=0` 临时换端口联调（解码端已支持） |
| 连上但角色不动 | 看解码端是否 `state=running`；确认配置 `outputs: websocket`；回放链路用 `cli run --chunks` 先验证有决策输出 |
| 按 D 崩溃 / 中文豆腐块 | 立即停用该版本，换已含 `getattr(event, "repeat", False)` 修复与中文字体的正式版 |
| 采集无信号/未校准 | **直接以键盘版或合成 replay 演示解码版可玩性**，如实标注，不伪造真人脑控 |
| 演示中途想快速复位 | 游戏 ESC/窗口退出走 `finally` 停客户端，重开即可；解码端重启后游戏 0.5s 自动重连 |
