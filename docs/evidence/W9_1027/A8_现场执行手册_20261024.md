## 7. 故障预案（现场照表处理）

| 症状 | 处置 |
|---|---|
| 游戏连不上解码器 | `netstat -ano \| findstr 8765` 查占用 → 关系统代理 → 确认 `outputs: [websocket]` → 仍不行临时换端口（解码端与游戏 `--ws-url` 同步改） |
| 连上但角色不动 | 看终端 1 是否 `state=running` 且有决策输出；先用 `--mode replay` 证明游戏输入层正常 |
| 启动即崩 / 按 D 崩溃 | 确认跑的是修复版 `game/platformer/main.py`（含 `getattr(event,"repeat",False)`）；崩溃立即停、换正式版 |
| 中文豆腐块 | 换正式版字体资源；不影响判定但影响观感，能修则修 |
| 首帧慢（约 2 s） | 正常，口播"约两秒出首帧" |
| 真人采集无信号/未校准 | **不演真人脑控**；改用键盘版或 mock/EDF 演解码版，如实标注 |
| 中途要复位 | Esc 退出游戏（走 `finally` 停客户端）；重启解码器后游戏 0.5 s 自动重连 |
