# M3 ITR 运行证据（2026-11-05）

> 用途：为 M3 报告/演示稿中的 Kappa、ITR 数字提供**可追溯的运行证据**。
> 归属：里程碑③（阎浩文），组长审阅中。数字仍属内部工程记录，对外发布口径以正式报告为准。

## 1. 脚本与命令

- 脚本：[`bci-decoder/scripts/m3/itr_report.py`](../../../bci-decoder/scripts/m3/itr_report.py)
- 运行环境：Windows PowerShell 5.1，`.deepworks/venv_m3`（MNE 1.11 / scikit-learn / pyriemann 0.12）
- 命令（仓库根）：

```powershell
& ".deepworks\venv_m3\Scripts\python.exe" "bci-decoder\scripts\m3\itr_report.py" --subjects 1,2,3,4,5,6,7,8,9 --pipeline both
```

协议：BCI IV 2a（BNCI2014-001），**左右手二分类**，`0train` 训练 / `1test` 测试；notch50 + 带通 8–30 Hz（4 阶）+ CAR；CSP / Riemann 切空间 + LDA；窗 2.0 s、步长 0.5 s，**trial 内 3 窗多数投票**。

## 4. 口径注意（重要）

本文件的 Kappa/ITR 是 **trial 内 3 窗多数投票** 的评测口径，**不等同于**游戏在线的稳定化逻辑（在线为：EMA 平滑 + 连续 3 次完全一致 + 置信度 0.6 门限）。详见 [`docs/M3_投票口径_离线与在线差异_20261105.md`](../../M3_投票口径_离线与在线差异_20261105.md)。
