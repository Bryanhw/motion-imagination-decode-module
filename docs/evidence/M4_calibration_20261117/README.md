## 2. 输入配置

- 数据：BNCI2014-001（BCI Competition IV 2a），**9 名受试者、22 真实通道**、2 类左右手（`left_hand`/`right_hand` 二类范式）
- 数据位置：`.deepworks/mne_data/MNE-bnci-data`（MOABB 缓存，已存在，无需联网）
- 预处理（与 M3 完全一致）：notch50 → BP 8–30 Hz（4 阶）→ 空间 CAR（减全通道均值）；滑窗 2.0 s / 步 0.5 s，从 cue 后 250 采样点起
- 管道：CSP（n_components=4, log=True, reg=None）+ LDA（lsqr, shrinkage=auto）；指标：窗口级 Kappa（与 M3 同一口径）
- **防泄漏铁律**：校准只用 `0train`（**session 1**）前 N trial/类；所有组共用同一测试集 `1test`（**session 2**）。**不混场**：任何 fold 的训练侧都不含 session 2，测试侧都不含 session 1。
- 图/表口径：测试（横轴之一）统一为 **session 2**；校准侧统一为 **session 1 前 N/类**（校准量 2/4/6 分钟即对应 N=10/20/30）。
- 个人校准梯度：N = 10 / 20 / 30（每类 trial 数，约 2 / 4 / 6 分钟语音时长）

要点：
- 免校准均值 **+0.191** 与已归档 M3 口径（≈0.19）**完全一致**，交叉验证了本次实现没有口径偏差。
- 个人校准整体优于免校准：均值从 +0.19 → **+0.36（N=20/类，Δ+0.17）**；N=30 略降（+0.35）但保持显著获益。
- 受益最明显：S03（0.36→0.81 @N10）、S08（0.81→0.84）、S01（0.22→0.50~0.59）、S09（−0.01→0.66 @N20）。
- 校准几乎无效的 受试（校准无增益）：**S02、S05、S06**（S05 校准后贴 0、S02≈0、S06 稳但不增）。
  这类个体在公开文献中即属难度较高/信噪比低的样本，属受试固有差异，不是流程问题；
  P1 已按预案排查（正则化 / 迁移校准两路均无法修复），见 `P1_正则化与迁移对照_20261117/`。
- 结论一句话：**用本人 2–4 分钟校准数据（N=20/类）即可把 Kappa 从≈0.19（接近乱猜）提升到≈0.36，个人校准证据链成立。**

## 4.1 审阅备注（组长 2026-11-17 数字审阅三项追加）

1. **S08 nocal 与 cal10 四列全同（kappa 0.8102 / acc 0.9051 完全一致）＝强巧合，非“cal10 没换模型”**。实证（DeepWorks 复跑 S08，`m4_calibration.py --subjects 1..9` 同口径）：cal10 确用 S08 自己 session1 前 10/类（20 trial）独立新建 CSP+LDA 训练，**模型参数与 nocal 完全不同**（CSP 滤波器矩阵逐元素差异最大约 1.7e6，LDA 系数亦不同）；**逐窗预测 432 窗中 48 窗不一致**；但两模型错误总数恰好相同（各 24 个一对一错），且 0→1 与 1→0 的误判量恰好互补对称（FP/FN 各差 1 反向），叠加测试集左右手窗口均衡（72×3=216/216）→ 两混淆矩阵除对角线上互换一对元素外完全等价 → po、pe 相同 → **kappa/acc 精确至 float 位全等**，round(4) 后四列全同。结论：**真巧合，模型确已切换，数字仍可信**（以 cap20/cap30 递增即可佐证：0.8102→0.8194→0.8380 单调，校准确实在起作用）。
2. **校准数据确认只用了 session 1**：脚本 `m4_calibration.py`（L191-197）校准分支仅取 `sess0 == '0train'` 前 N/类训练，测试仅取 `1test`，代码即防泄漏铁律；无任何 fold 混用。图例已补注（见 §2）。
3. **S03 / S09 的 N=10 反常＝小样本噪声，不影响结论**：S03 N=10 异常高（0.81）、S09 N=10 反而低于 nocal（−0.13），到 N=20/30 回到正常区间（0.6~0.66）。原因：N=10/类（20 trial）时 CSP 协方差估计方差大，单受试极端值属预期；均值口径下 N=20 达峰结论不受单受试噪声影响。
4. **口径为窗口级（保守）**：本表为每窗口独立预测的窗口级 Kappa（严格口径）。叙事可补一句：**trial 级投票口径（每 trial 内 3 窗投票定标）通常更高**（M3 已用同一思想：trial 级 3 窗投票 csp 0.466/riemann 0.481）。
