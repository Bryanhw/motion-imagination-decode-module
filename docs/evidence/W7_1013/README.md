# 证据归档目录（Evidence）

本目录用于存放**里程碑验收证据**，对应 `docs/MVP规格说明书.md` §10.2 / §10.3 与
`docs/在线解码模块设计说明.md` 附录 A 的留档要求。

## 命名规则

`docs/evidence/W{n}_{日期}/` —— 例：`W7_1013/` 表示第 7 周、2026-10-13 那一批证据。

## 每个里程碑要放什么

| 内容 | 说明 |
|---|---|
| 命令与原始输出 | 例：`python -m pytest` 的完整输出、`cli benchmark` 的 JSON |
| 环境信息 | Python 版本、依赖版本、操作系统（可用 `pip freeze` 快照） |
| 数据与配置 | 使用的 config 文件、数据来源标识（**不得放受限数据集本身**） |
| 结论与偏差 | 与预期不符的地方要写清楚，不要只放"好看"的结果 |

## 红线（不得违反）

1. **合成数据 / mock 的自检数字（含交叉验证 ≈ 100%）不是算法成绩**，
   可以归档为"工程自检证据"，但**不得**作为准确率报告。
2. **真实准确率只认里程碑 ③**（公开数据集：`moabb` + BCI IV 2a）。
3. 未训练 / 未置信时，链路必须输出 `idle` —— 相关证据（日志）也要归档。
4. 大文件（`.joblib`、原始 EEG）**不入库**，只登记路径与校验值（见 `.gitignore`）。
