## 1. 项目理解：企业真正要的是什么

企业材料里的关键词其实指向三件事，优先级从高到低：

1. **在线数据处理**——这是企业的刚需。离线刷到 85% 但单次推理要 2 秒，对轮椅和游戏毫无价值。
2. **运动想象解码准确率提升**——在"可实时"的前提下把准确率往上抬。
3. **多脑区信息融合（枕叶、前额叶）**——这是企业自己也不确定可行性的**探索性方向**，属于项目的"创新加分项"，不是第一版必须做出来的东西。

### 学生团队最容易踩的三个坑

- **坑一：只做离线，不做在线**。交付时企业问"能实时跑吗"，答不上来。
- **坑二：一上来就上深度学习**。数据少（单个被试往往只有几百个 trial），EEGNet 在跨被试上经常打不过 CSP+LDA 或黎曼几何方法。
- **坑三：忽视"个体差异/跨次漂移"**。这是脑机接口落地失败的头号原因，必须有专门的实验设计去验证，而不是最后才想起来。

### 建议的成功标准（写进项目书）

> 在公开数据集上，二分类运动想象达到可复现的基线（说明方法有效）；
> 在自采或第三方流式数据上，端到端**响应时间 ≤ 3 s**（其中滑窗累积约 2 s、单次计算 p95 < 50 ms），分类稳定输出（说明可落地）；
> 跨被试实验相比"每被试独立训练"的精度下降可量化、可解释（说明有泛化能力）。

> **关于"延迟 ≤ 200 ms"这个常见误区的更正**：
> 许多资料（包括本规划 v1.0）把"端到端延迟 ≤ 200 ms"写成目标，这在运动想象范式下**物理上做不到**。实测分解为：
> `T_response ≈ T_accumulate(滑窗长度) + T_compute`，其中 2 s 窗口占 **99.9%**，计算只占 **0.1%**（现有自检量级 p95 ≈ 2 ms）。
> 因此**延迟瓶颈不在算法而在窗口长度**——优化模型、上 GPU 几乎没有帮助；真正有效的手段是缩短窗口，但窗口越短准确率越低。
> **正确做法：先定游戏节奏，再倒推窗口长度，最后在窗口内优化准确率。**（详见《在线解码模块设计说明》第 3 节）

## 2. 技术链路逐环节拆解

主链路：**原始 EEG → 滤波 → 预处理 → 特征提取 → 分类 → 运动意图**

| 环节 | 目标 | 主流方法 | 大一团队注意点 |
|---|---|---|---|
| **信号采集** | 拿到干净、带事件标记的数据 | 10-20 系统电极、LSL 时间戳、Neuracle / OpenBCI | 初期先用公开数据集，别一上来自采 |
| **滤波** | 保留运动想象相关节律，去工频与漂移 | 带通 8–30 Hz（μ 8–13 / β 13–30）、50 Hz 陷波、0.1–1 Hz 高通去漂移 | 在线必须用**因果滤波**，会带来相位延迟，需单独测 |
| **预处理** | 去伪迹、统一尺度、分段 | CAR 重参考、ICA + ICLabel、ASR、坏道插值、epoch 分段 + 基线校正 | 眼电/肌电是最大污染源；ICA 在线实现要用滑窗或参考投影 |
| **特征提取** | 把高维 EEG 变成可分特征 | 频带功率(PSD)、CSP / FBCSP、小波/STFT、**协方差矩阵 + 黎曼几何**、功能连接 | CSP 必须做**正则化**，否则过拟合；协方差特征对噪声敏感需收缩估计 |
| **分类** | 输出运动意图 | 传统：LDA、SVM、黎曼分类器；深度：EEGNet、ShallowConvNet、FBCNet、TSception | 先传统后深度，用传统基线证明深度模型确实更强 |
| **在线解码** | 持续输出稳定判断 | 滑动窗（2–4 s）+ 步长（0.25–1 s）、决策平滑/投票、置信度门限 | "稳定"比"瞬时准"更重要，要做平滑与拒识 |

### 2.1 为什么推荐"黎曼几何"作为传统方法的主力

- 运动想象的本质差异是**协方差结构的差异**，协方差矩阵天然保留了这个信息；
- 配合**欧氏对齐（Euclidean Alignment, EA）**，跨被试性能提升非常明显，这是近几年 MI-BCI 最实用的进展之一；
- 计算量可控、易在线（可以滚动估计协方差），非常适合"既要准又要实时"的场景；
- 相比深层网络，它**对数据量要求低**，正适合大一团队拿不到大量被试数据的现实。

## 3. 核心难点 → 对策映射

| 企业指出的难点 | 具体表现 | 可行对策 | 验证方式 |
|---|---|---|---|
| **低信噪比** | EEG 幅度 μV 级，伪迹强 | ASR + ICA/ICLabel；协方差收缩正则化；多 trial 平均；对肌电做高频能量检测并剔除 | 对比有/无伪迹处理下的准确率与方差 |
| **个体差异** | 每人脑区活动模式不同 | 欧氏对齐、迁移成分分析(TCA)、域自适应、微调 | **留一被试交叉验证（LOSO）** |
| **跨次实验漂移** | 今天准明天不准 | 在线自适应归一化、滑动窗重估协方差、少量在线校准 trial | 同被试跨 session 实验对比 |
| **多脑区融合** | 枕叶 α、前额叶参与认知/注意 | 分区特征 + 多分支网络 + 区域注意力/加权融合 | 消融实验：单区 vs 多区 |
| **在线实时性** | 离线算法不可直接搬 | 因果滤波、增量特征、模型轻量化（ONNX/量化）、固定缓冲队列 | 测**端到端延迟**与**吞吐** |
| **分类准确率** | 4 类 MI 公开数据集普遍 60–75% | 滤波器组、集成、数据增强、迁移学习 | 与公开基线论文对齐复现 |

## 5. 数据集与评测基准

| 数据集 | 被试数 | 类别 | 通道 | 用途 |
|---|---|---|---|---|
| **BCI Competition IV 2a** | 9 | 4 类（左/右手、双脚、舌头） | 22 | 最经典的 MI 基准，必跑 |
| **BCI Competition IV 2b** | 9 | 2 类 | 3 (C3/Cz/C4) | 少通道、贴近落地场景 |
| **OpenBMI** | 54 | 2/4 类 | 62 | 被试多，**跨被试泛化**首选 |
| **PhysioNet EEG Motor Movement** | 109 | 2/4 类 | 64 | 数据量大，适合深度模型预训练 |
| **High-Gamma Dataset** | 14 | 4 类 | 128 | 高密度电极研究 |

### 评测指标定义

- **准确率 Accuracy**：最直观，类别不平衡时要谨慎；
- **Cohen's Kappa**：扣除随机猜中，MI 领域标准；
- **ITR（信息传输率，bits/min）**：

  `ITR = [log₂N + P·log₂P + (1−P)·log₂((1−P)/(N−1))] × 60/T`

  其中 N 为类别数，P 为准确率，T 为单次决策耗时（秒）。**ITR 同时反映准确率与速度**，是最能打动企业的指标；
- **端到端延迟**：从数据进入缓冲区到输出意图的时间，在线模块必须实测；
- **泛化性**：LOSO 准确率 − 被试内准确率 的差值。

### 经典性能参考（便于判断自己是否达标）

- BCI IV 2a 四分类：CSP+LDA 约 68–72%；FBCSP 约 68%；EEGNet 约 60–70%；黎曼方法约 70–75%；
- BCI IV 2b 二分类：可达 75–80%；
- **注意**：跨被试、跨 session 时普遍掉 10–20 个百分点，这才是企业真正关心的数字。

### 可选项：多脑区融合探索（阶段 4 内按剩余时间取舍）
- **任务**：按通道位置划分运动区 / 枕叶 / 前额叶，做分区特征；尝试特征级拼接或分区独立分类 + 决策融合。

## 7. 可能的发展方向（可用于选题/论文/专利）

| 方向 | 说明 | 难度 | 企业价值 |
|---|---|---|---|
| **跨被试迁移学习 / 域自适应** | 新用户免校准或少量校准即可用 | 中高 | ★★★★★（决定产品能否规模部署） |
| **多脑区融合解码** | 运动区 + 枕叶 + 前额叶联合建模 | 中 | ★★★★（企业点名方向） |
| **在线自适应校准** | 使用中持续微调，抵抗漂移 | 中高 | ★★★★★ |
| **轻量化 / 边缘部署** | 模型压缩、量化，跑在嵌入式或边缘盒子上 | 中 | ★★★★（轮椅等移动设备刚需） |
| **伪迹鲁棒解码** | 患者/康复人群运动伪迹多，需强鲁棒性 | 中 | ★★★★（康复场景真实痛点） |
| **多模态融合** | EEG + 眼动/EMG/近红外(fNIRS) | 高 | ★★★★（提高可靠性） |
| **生成式数据增强** | 用扩散/VAE 生成 EEG 缓解数据不足 | 高 | ★★★ |
| **可解释性** | 可视化脑区贡献，辅助医生/患者信任 | 中 | ★★★ |

**建议**：主攻 **跨被试迁移 + 在线自适应**，把多脑区融合作为创新点并行探索。

## 8. 大一学生的知识补全路径

**按优先级排序，避免"什么都学一点、什么都做不出"：**

1. **数学基础**：线性代数（协方差、特征值、矩阵分解）、概率统计（贝叶斯、假设检验）、信号与系统（傅里叶、滤波、采样定理）。
2. **编程基础**：Python → NumPy / SciPy / Matplotlib → Pandas。
3. **领域基础**：脑电生理基础（10-20 系统、μ/β 节律、ERD/ERS）→ MNE 官方教程。
4. **机器学习**：scikit-learn 入门 → 交叉验证、正则化、过拟合概念。
5. **深度学习**：**本版不要求**（10 周周期内不做深度模型）。时间充裕再跑 Braindecode 示例、读 EEGNet 论文。

**推荐学习资源**：
- 《脑机接口导论》（入门概念）、MNE-Python 官方文档与教程（最实用）
- MOABB 官方 benchmark 文档（学会规范做对比实验）
- 综述：*Deep learning for EEG-based BCIs*、*Riemannian geometry for EEG classification*
- 论文：EEGNet (Lawhern 2018)、FBCNet (2021)、EEG-Conformer、EA (He & Wu 2020)

## 9. 风险与建议

| 风险 | 影响 | 应对 |
|---|---|---|
| 团队全是大一，编程/信号基础薄弱 | 进度拖慢 | 阶段 0 必须扎实；先复现再创新 |
| 拿不到真实设备或数据 | 无法验证在线 | 早与企业确认设备型号与数据获取方式；优先用公开数据集+流式回放 |
| 盲目追深度模型 | 精度不升反降 | 严格用传统基线做对照，指标说话 |
| 忽视实验记录 | 结果无法复现 | 强制使用 WandB/TensorBoard + Git |
| 以离线指标交付 | 企业无法使用 | 把"在线延迟"从第一天就列为考核指标 |
| 数据合规 | 人体数据伦理风险 | 采集真实被试前必须走**伦理审查 + 知情同意** |
| **课程节点比技术进度硬** | 10/27 交不出 MVP | 里程碑不可挪；**先降功能不降节点**——MVP 只保骨架三项 + 弹球 Demo |
| **为应付评审赶造真实数据结果** | 学术风险 | W9 只演示链路与延迟；真实数字留到 ③ 中期评审（11/10） |
| **评审前过程证据不齐** | 直接丢分 | `docs/evidence/W{n}_{日期}/` 按里程碑归档，**评审前 24h 齐备** |
| **Demo Day 才第一次完整演示** | 现场翻车 | ④ Beta 起每周演练，⑤ 前完成至少 3 次彩排 |

### 与企业沟通时建议主动确认的问题

1. 企业现有采集设备的型号、通道数、采样率、是否有 SDK / LSL 支持？
2. 期望的类别数（2 类还是 4 类）？单次决策允许的最长响应时间是多少？
3. 脑控轮椅/游戏当前的接口形式（串口？网络？定制 SDK？）需要什么格式的输出？
4. 是否已有企业侧采集的实测数据可以共享（哪怕少量）？
5. 验收标准由谁定义、以什么数据为准？
