# 唯一规格说明（M2 · 一页纸）

> 本页是全项目**主线口径的唯一入口**：给评审与新人 5 分钟看懂"我们做的到底是什么"。
> 逐字段、逐参数的权威定义以 [`MVP规格说明书.md`](MVP规格说明书.md)（冻结版）为准——本页只做定调与索引，**冲突时以规格书为准**。
> 建立日期：2026-10-29（M2 评审前）。回应外部评估报告 gap A："主线、输入、模型、客户端、验收日期，一页说清，不再互相矛盾。"

| 维度 | 唯一口径 | 出处 |
|---|---|---|
| **主线** | 单进程在线解码链路 `sources → buffer → pipeline → outputs`：8 通道脑电 → 滑窗 2.0 s / 步长 0.5 s → CSP + log-方差(4 维) + LDA → 稳定器（EMA 0.4 + 连续 3 次新候选确认）→ **冻结 9 字段 JSON 决策消息**，三路输出 console + jsonl + **WebSocket** | [MVP规格说明书](MVP规格说明书.md) §4/§5；[TechDesign-BCI-Decoder-MVP](TechDesign-BCI-Decoder-MVP.md) |
| **输入** | M2 演示数据源只有两种：① **mock**（合成数据，工程自检，不报告性能）② **replay**（PhysioNet EEGMMIDB 公开数据集真实采集，本项目**仅回放、不新采**）。键盘仅用于游戏端 A1 跑通验证。**LSL 真人设备接入属里程碑④（12/01），M2 不演示**（设备型号/通道顺序/流名称待企业书面确认） | 规格书 §5、§11.3；[MVP_PRD](MVP_PRD.md) §4.5 |
| **模型** | **CSP + log-方差（4 维）+ LDA**（v1.1.3，2026-10-20 自频带功率 16 维切换）；**OOD 域内检测**灰度同参启用（v1.1.4，D3 拍板 8/8 通过）；在线**因果滤波**（sosfilt + 跨块 zi，禁用 filtfilt）；**未训练或不可信时恒输出 `idle`，绝不随机左右** | 规格书 §9 变更记录；`bci-decoder/tests/` |

| **延迟口径**（三个数分开说） | ① **首个结果** ≈2.1 s（等满首窗 2.0 s + 启动 <0.1 s）② **稳态节奏** 每 0.5 s 一条指令，末样本→显示 ≈19 ms（p95）③ **首次有效动作**（新类别出现→游戏动作）最坏 ≈3.5 s = 2.0 窗 + 1.5 确认等待 + 0.02 计算传输显示。**"99.8% 时间在攒窗口"不是已测事实，只是单次决策构成的理论占比**（外部评估 §4.3 整改） | [A5 延迟演示页](evidence/W9_1027/01_延迟/A5_延迟分解演示页.html)；A9 启动计时 |

## 一句话版本（评审开场可用）

> 我们把 8 通道运动想象脑电，经 2 秒滑窗 CSP+LDA 解码成"左手/右手/idle"决策，通过 WebSocket 以每 0.5 秒一条的节奏驱动横版闯关游戏 MI Pixel Run；M2 阶段用 mock 与公开数据集回放验证全链路工程指标（延迟、断线安全、稳定性），不报告准确率，真实设备接入在里程碑④。
