## 1. 项目使命与唯一成功标准

### 1.1 使命

> 做出一条从原始脑电到"运动意图"的**在线实时解码链路**，封装成**可被脑控游戏 / 脑控轮椅直接调用的模块**。

### 1.2 唯一成功标准（不可替代）

> **能不能驱动游戏，是衡量我们成败的唯一标准。**

不是"跑了多少实验"，不是"用了多先进的模型"，而是：
**同学戴上脑电帽、想象动作、游戏里的挡板真的动了。**

### 1.3 我们交付的"产品"是什么

一句话：**一段 JSON 消息流。**

```json
{"label": "left", "confidence": 0.83, "probs": [0.83, 0.17], "state": "running", ...}
```

游戏拿到它就能驱动角色。字段定义见《MVP 规格说明书》4.2（**已冻结**）。

## 2. 项目目标

### 2.1 分层目标

| 层级 | 目标 | 节点 | 是否必做 |
|---|---|---|---|

| **第三层：算法增强与交付** | 黎曼 + 欧氏对齐、校准流程、Docker | ④⑥ 12/01–12/15 | 必做 |

### 2.2 明确不做（写进章程，避免中途跑偏）

- 不造采集硬件；
- 不做医疗诊断级产品；
- **不做 4 分类**（本期冻结为 2 类 + `idle`）；
- **不上深度学习**（数据量不够，跨被试常打不过传统方法，且对延迟无帮助）；
- **不采集真实患者数据**（伦理审查未走完）；
- 不做脑控轮椅实物（本期用游戏打磨闭环，轮椅是下一期的复用目标）。

## 3. 成功指标（验收口径）

### 3.1 技术指标

| 指标 | 目标值 | 节点 | 说明 |
|---|---|---|---|
| 判断准确率（Kappa） | **> 0.3** | ③ 11/10 | 扣除"瞎猜蒙对"后的真实水平；0.6 以上算好 |
| 端到端响应时间 | **≤ 3 s** | ② 10/27 | 其中 2 s 是等数据，必须实测并如实报告 |
| 单次计算耗时 | **p95 < 50 ms** | ② 10/27 | 用 `cli benchmark` 实测 |
| 误触发 | 什么都不想时**不能乱动** | ② 10/27 | 靠置信度门限 → `idle` 保证 |
| 稳定性 | **连续 1 h 不崩、内存不涨** | ④ 12/01 | 长跑脚本验证 |
| 伪在线一致性 | 回放准确率与离线**差 < 5%** | ③ 11/10 | 验证因果滤波没搞坏东西 |

### 3.2 体验指标（同样算验收）

准确率不是唯一标准。还要看同学玩的时候：

- 有没有**"我在控制它"**的感觉（脑控感）；
- 累不累（认知负荷，用简版 NASA-TLX）；
- 愿不愿意再玩一次。

> **做法**：每次试玩后填一份 **5–8 题简版问卷**；③（11/10）前至少 **3 名同学**完成实测。

### 3.3 过程指标（课程评审要求）

> 每次评审**同时提交三件套**：**当前版本 + 过程证据 + 下一轮决策**。

| 项 | 要求 |
|---|---|
| 当前版本 | 可运行、可演示，不是 PPT |
| 过程证据 | `docs/evidence/W{n}_{日期}/` 齐备（**评审前 24 h**） |
| 下一轮决策 | 明确写出下一步做什么、优先级怎么排、砍了什么 |

### 4.1 角色表

| 姓名 | 角色 | **主责（一块）** | **配合（一块）** |
|---|---|---|---|
| **蓝喜阳**（组长） | 统筹 + 算法 | 对接企业、定接口与里程碑、盯进度、主持例会 | 参与算法方案与实验设计 |
| **阎浩文** | 算法主力 | 洗数据、找特征、训练判别程序、跑准确率实验 | 单元测试（特征/分类器/稳定化） |
| **黄凯森** | 数据评测 + 游戏 | 下载公开数据集、标准评测、**脑控弹球游戏**、备演示 | 用户测试与问卷 |
| **王释贤** | 工程 | 数据管道、通信接口（WebSocket）、速度优化、打包部署 | 接口联调、延迟压测 |

### 4.2 分工原则（四条）

1. **每人一块主责 + 一块配合**，不设"只做文档"的人——**人手紧，必须人人出代码**；
2. **游戏与算法必须并行**：黄凯森**先用键盘**把弹球做出完整玩法，**不等算法完成**；
3. **只有一个人会跑 = 没有人会跑**：环境与流程必须 4 人都能独立执行（对应验收 A1）；
4. **接口只有一个出口**：对外沟通由蓝喜阳出口；接口契约由王释贤维护，变更走流程。

### 4.3 两条工作线的交汇点

```
算法线（阎浩文）  ── 预处理/特征/分类 ──┐
                                        ├──▶ 【replay 伪在线回放】──▶ 一致性验证
工程线（王释贤）  ── 缓冲/管道/接口  ──┘                              │
                                                                      ▼
游戏线（黄凯森）  ── 键盘版弹球 ──────────▶ 换解码输入 ────────▶ 脑控弹球 Demo
                                                          （蓝喜阳统筹节点与验收）
```

> **replay 回放是两条线的交汇点**：算法同学验证"离线方法在在线约束下还成立吗"，
> 工程同学验证"管道没把数据搞坏"。**这个测试必须做**，它是 ③ 阶段"差 < 5%"的前置。
