## 6. 口径与纪律

1. 未训练 / 模型缺失 / 置信度不足 → 必须输出 `idle`；在线链路只用因果滤波（禁 `filtfilt`）。
2. 输出字段冻结（`t_data/t_wall/label/label_id/confidence/probs/state/compute_ms/window_seconds`），`label_id == -1` 当且仅当 `label == "idle"`。
3. 通道顺序 `C3, Cz, C4, CP3, CP4, P3, P4, Oz` 不得重排；类别 2 类 + `idle`；滑窗 2.0 s、步长 0.5 s。
4. 现场演示用 mock/replay 合成数据时**如实标注**，不得说成"真人脑电实时控制"，且不报合成数据准确率。
5. 每次开工先读 `MEMORY.md`；改代码前后跑最小测试并同步更新 MEMORY。
