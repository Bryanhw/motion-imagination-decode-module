## v3 命令与代码的已知差异

1. v3 测速示例为 `configs/default.yaml --chunks 200`；本机三次原始数据为 `configs/demo_online.yaml --chunks 600`，分开保存。`default.yaml` 步长当前为 0.25 s，与 v3 冻结值 0.5 s 不符，先对齐配置口径，再决定补跑；不覆盖已有三份日志。
2. v3 引擎示例 `Engine.step` 对应现有 `DecoderEngine.run/push`；长跑脚本复用后者。
3. 当前长跑脚本接受 `--seconds`，5 分钟为 `--seconds 300`，一小时为 `--seconds 3600`；v3 附录的 `--minutes 60` 尚不可直接执行。
4. 所有命令仍在 `bci-decoder/` 下使用 `.\.venv\Scripts\python.exe`，无需用全局 Python。
