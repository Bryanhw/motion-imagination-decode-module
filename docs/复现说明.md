1. v3 测速示例为 `configs/default.yaml --chunks 200`；本机三次原始数据为 `configs/demo_online.yaml --chunks 600`，分开保存。`default.yaml` 步长当前为 0.25 s，与 v3 冻结值 0.5 s 不符，先对齐配置口径，再决定补跑；不覆盖已有三份日志。
