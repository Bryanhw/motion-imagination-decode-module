## 1. 实验设计规格（D1，阎浩文照此施工）

- **数据**：BCI Competition IV 2a（BNCI2014-001），9 受试者，左右手二类，沿用 M3 预处理与 22 真实通道。
- **免校准组**：其余 8 人数据训练 → 测目标受试者 **session 2**（即 M3 LOO 口径复用，预期 kappa≈0.19）。
- **个人校准组**：目标受试者 **session 1 前 N trial** 训练个人 CSP+LDA → 测**同一 session 2**（同测试集才公平）。
- **校准梯度**：N = 10 / 20 / 30 trial 每类（约 2 / 4 / 6 分钟校准量），出"校准数据量–Kappa"曲线。
- **防泄漏铁律**：校准只用 session 1，测试只用 session 2；任何 fold 不得混用。
- **输出**：对比 csv + 曲线 png + 复现说明（按 X10 统一模板：运行身份/输入配置/操作命令/结果/附件）。
- **风险预案**：小样本 CSP 不稳 → 先试正则化；仍差 → 8 人模型初始化 + 个人数据微调（迁移校准），两条路都留记录。

## 4. 红线与口径

1. replay = 公开数据集真实采集回放，演示画面/口播必须标注"非现场真人采集"。
2. 校准对比用 **Kappa**（沿用 M3 口径），不报裸准确率；免校准≈0.19 与校准后数字必须同测试集同口径。
3. 校准时长叙事如实：梯度曲线若 20 trial/类 才够，就说"约 4 分钟校准"，不硬凹"两分钟"。
4. 真人原始数据不入库（本周不涉及真采）；所有新证据按 X10 模板记录运行身份。
