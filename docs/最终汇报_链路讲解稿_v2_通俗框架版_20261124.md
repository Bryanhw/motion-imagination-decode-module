## 〇、一句话开场（10 秒，讲给大一新生）

> “我们做的不是‘让游戏会动’，而是——**你心里想着‘往左’，机器把你的念头读出来，翻译成游戏听得懂的指令**。关键是：它读不准的时候，就乖乖什么都不发。”

**打比方**：想象你头上戴了个对讲机，专门听大脑“想动左手、想动右手”时的电波声。

**严谨概念（专业名词）**：这一整套“读念头、发指令”的系统，专业上叫 **脑机接口（BCI, Brain-Computer Interface）**；“心里想着动左手/右手、但手不动”这个动作，叫 **运动想象（MI, Motor Imagery）**——它是 BCI 里最经典、最稳的一种范式，也是本项目解码的对象。

## 一、链路一页图（指图讲，底下每个概念都有大白话）

```
脑子里“想往左/想往右”
   │
   ▼ ① 电极收声：8 个点放在头顶固定位置（C3/Cz/C4/CP3/CP4/P3/P4/Oz），250 次/秒采样
   │        〰 用专业话说：8 通道 EEG，250Hz
   ▼ ② 洗数据：去掉市电杂音(50Hz)、只留 8–30Hz 有用段、去掉全脑共同背景(CAR)
   │        〰 因果滤波 sosfilt + 跨 chunk 传状态（不能偷看未来）
   ▼ ③ 攒一段再判断：拿 2 秒一段，每 0.5 秒出一个判断
   │
   ▼ ④ 找特征：给“左手信号”和“右手信号”各配一副放大镜（CSP 共空间模式），取 log-方差
   ▼ ⑤ 分类：在放大后的图里画一条分界线（LDA），输出“像左/像右”的把握
   │
   ▼ ⑥ 三道闸：连续 3 次同意见 → 把握≥0.6 → 才发动作；没把握就 idle
   ▼ ⑦ 发消息：一张固定格式的小纸条（JSON）──► 游戏
```

**口播主句**（讲给大一新生的一句话路线）：
“头顶收信号 → 洗掉杂音 → 攒两秒 → 放大左右差异 → 画线判断 → 三道闸把稳 → 发指令给游戏。”

**链路七步对照的专业名词**（从①到⑦依次是）：
EEG 采集 → 预处理滤波（Notch / Band-pass / CAR）→ 滑动窗口 → CSP 特征提取 → LDA 分类 → 稳定化门控（EMA / 投票 / 置信度 / OOD）→ 消息契约（JSON）输出。

## 二、分段讲解框架（每段：讲什么 → 打比方 → 严谨概念 → 红线提醒）

### 第 1 段｜为什么是 8 个点、放在头顶这块位置

- **讲什么**：只用 8 个通道，位置固定（C3/Cz/C4/CP3/CP4/P3/P4/Oz）。
- **打比方**：想象想动左手时，右半脑的“运动区”电台会变安静（信号减弱），想动右手时反过来。C3/C4 正好盖在左右运动区上，CP/P 是旁边帮忙看的辅助位，Oz 在脑后当参照。
- **一句话**：**放对位置才听得到意图**；而且这个顺序是固定的，乱换顺序结果就会反过来。
- **严谨概念（专业名词）**：电极的摆放位置遵循 **国际 10-20 导联系统（10-20 System）**；C3 / C4 对应的是**大脑初级运动皮层（M1）的左右手代表区**。“想动一边手脚、那边皮层节律功率就下降”这个现象，专业叫 **事件相关去同步（ERD, Event-Related Desynchronization）**——我们正是靠它在 8–30Hz（mu/beta 节律）上的变化来分辨左/右意图。
- **红线提醒**：顺序即语义，8 通道顺序固定（C3, Cz, C4, CP3, CP4, P3, P4, Oz）。

### 第 2 段｜为什么先洗掉 50Hz、再只留 8–30Hz、还要减掉共同背景

- **讲什么**：三个步骤——陷波 50Hz、带通 8–30Hz、CAR。
- **打比方**：① 50Hz 是家里电插头的“嗡嗡声”，电极线像天线一样会收到，必须掐掉；② 脑电里真正有用的频段就是 8–30Hz（mu/beta 节律），别的都是噪声，砍掉；③ 全脑都有的共同背景（比如眨眼）减掉，只留下“不一样的部位”的信号。
- **严谨概念（专业名词）**：这一步叫 **信号预处理（Preprocessing）**，由三个滤波器组成：① **陷波滤波器（Notch Filter）**——中国市电是 50Hz，所以掐掉 50Hz；② **带通滤波器（Band-pass Filter）**——保留 8–30Hz 的 mu/beta 节律；③ **共平均参考（CAR, Common Average Reference）**——减去全脑共同成分，抑制眨眼等共模干扰。注意：这里出现了一个“在线能不能用”的严谨问题——见下方红线。
- **红线提醒（必答）**：在线为什么不能用“零相位滤波”？——因为它要偷看未来的数据。在线只能看过去，所以用因果滤波 **sosfilt**，并且**跨 chunk 传状态**，否则每半秒重新开始滤波，边界会跳变，解码会乱。

### 第 3 段｜为什么攒 2 秒、每 0.5 秒判断一次

- **讲什么**：2.0 秒窗攒数据，每 0.5 秒滑动一次、出一个判断。
- **打比方**：脑电像广播里的沙沙声，单看一瞬没有规律；攒足 2 秒才能看见稳定模式（8Hz 信号 2 秒里有 16 个周期）。每 0.5 秒推一次，游戏“每半秒收到一次指令”，跟手又不累。
- **严谨概念（专业名词）**：这叫 **滑动窗口（Sliding Window）**：窗口宽 **2.0 秒（=250Hz × 2.0 = 500 个采样点）**，步长 **0.5 秒（=125 点）**，相邻窗口有 1.5 秒重叠。这是实时 EEG 分类的标准做法——信息被反复利用、判断又跟手。
- **一句话**：窗口/步长是冻结契约（2.0s / 0.5s），改了会破坏游戏节奏和验收口径。

### 第 4 段｜为什么用 CSP + LDA（而不是什么高大上的深度网络）

- **讲什么**：特征用 CSP（共空间模式）+ log-方差，分类用 LDA。
- **打比方**：
  - 单看一个电极看不出“左”还是“右”；CSP 是给左手信号和右手信号**各配一副专属放大镜**，让“左”的信号在这副镜下哗地变大、“右”的变小（反之亦然）；
  - 放大完取一个叫 log-方差的数当“特征”，把两类的差别拉得更开；
  - LDA 是在放大后的图里**画一条分界线**，输出“像左/像右”的把握。它算得非常快，实时能用。
- **严谨概念（专业名词）**：CSP 全称 **共空间模式（Common Spatial Patterns）**——对两类协方差矩阵联合对角化，找出使“左/右两类方差差异最大”的空间滤波器；随后取 **log-方差（Log-variance）** 作为判别特征；分类器用 **线性判别分析（LDA, Linear Discriminant Analysis）**——在特征空间画出线性分界面，最大化类间距离、最小化类内距离，直接输出后验概率。三个组件加起来，就是经典的运动想象 BCI 解码小管线上“特征提取 + 分类”的标准组合。
- **一句话（应对“为啥不用深度学习”）**：深度网络要海量数据，我们是每人几分钟校准、几十个样本，CSP+LDA 是“样本少也能学”的最稳选择。

### 第 5 段｜为什么“三道闸”必须有（这是全场的重点）

- **讲什么**：分类后还有三道闸——平滑(EMA) → 连续 3 次同意见 → 把握≥0.6；不一致就保持上一次，把握不足就 idle。
- **打比方**：单次判断像抛硬币，会抖。三道闸就像考勤：**连续三次都说同一句话才算数**；把握不够干脆喊“不知道”（idle），游戏就什么都不做。
- **严谨概念（专业名词）**：这一步叫 **决策后稳定化（Post-hoc Stabilization / Decision Gating）**，由三块组成：① **指数滑动平均（EMA, Exponential Moving Average）**——把相邻判断平滑掉抖动（α=0.4）；② **一致性投票（Majority Voting）**——连续 3 次结果一致才切换输出，否则保持上一次；③ **置信度门限（Confidence Threshold）**——后验概率 < 0.6 就落回 `idle`。此外，面对“没训练 / 陌生分布”，链路还带**域外检测（OOD, Out-of-Distribution）**（Mahalanobis 距离 + χ² 分位）来兜底。
- **红线提醒（必答）**：**没训练时为什么是 idle？**——没训练时分类器对“左/右”各给 50% 把握，低于 0.6 的门槛，链路设计上就强制输出 idle。**这是链路自己保证的，不是靠人守纪律**：绝不乱发左右指令。

### 第 6 段｜为什么发一张“固定格式的小纸条”

- **讲什么**：最终输出一条固定 9 字段的 JSON（label / label_id / confidence / probs / state / compute_ms / window_seconds / t_data / t_wall）。
- **打比方**：解码端和游戏端像两个部门，靠一张**格式写死的小纸条**沟通。模型、通道、滤波怎么改都不影响游戏——只要纸条格式不变，游戏零改动。
- **一句话**：字段已冻结，`label_id == -1` 当且仅当 `label == "idle"`；要加减字段得走变更流程。
- **严谨概念（专业名词）**：这张“小纸条”在工程上叫 **消息契约（Message Contract）**——解码端与游戏端之间接口的**标准化序列化格式（JSON）**。9 个字段已冻结（`t_data / t_wall / label / label_id / confidence / probs / state / compute_ms / window_seconds`），且约束 `label_id == -1 ⟺ label == "idle"`。这种“接口不随实现变”的设计，叫 **契约优先 / 解耦（Contract-first Decoupling）**：上下游各自独立演进，互不影响。

## 三、收尾框架（接个人校准 + 分屏录屏）

> 这一段让全场“落地到人”，讲完直接切录屏。

- **讲什么**：前面是“同一套链路人人都能跑”。但现实是：**每个人的脑电指纹不一样**。
- **数字（公开数据回放 / 工程自检口径）**：拿别人的模型直接测新人，Kappa ≈ 0.19（接近随机）；本人做约 4 分钟想象任务校准（每类 20 trial）后，Kappa 升到 **0.36**，过 0.3 达标线。
- **打比方**：就像每个人的嗓音不同，脑电也是“千人千声”；先让本人“录个声”（校准），机器才认得他。
- **严谨概念（专业名词）**：衡量“比随机好多少”的指标叫 **Cohen‘s Kappa 系数（κ）**——0.3 是 BCI 竞赛常用的达标线；“先给本人录个声”叫 **个性化校准（Subject-specific Calibration）**，也就是用本人脑电重新训练分类器，解决**跨受试差异（Inter-subject Variability）**。“录完声还不行”的人，对应 BCI 领域公认的 **“脑机盲”（BCI Illiteracy / BCI Inefficiency）** 现象——这是范式层面的个体差异，不是算法缺陷。
- **再补一句（个体差异）**：有人校准后还是弱——这是个体差异（BCI illiteracy）；所以我们设计了**试玩门**，能玩才交付，不稳就加数据，**不承诺任何真人数值**。
- **切录屏**：“校准完的个人模型回放，直接驱动我们的小游戏——左边游戏，右边解码器：实时波形、实时决策日志、状态灯。这就是从‘念头’到‘指令’的完整闭环。”
