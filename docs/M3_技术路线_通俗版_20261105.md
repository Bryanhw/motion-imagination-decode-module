# M3 技术路线 · 通俗版（2026-11-05）

> 给完全没接触过脑机接口的同学看：**每一环为什么必须有、用大白话怎么理解**。
> 严格版见 `docs/M3_讲稿技术原理详解_20261105.md`；本文只讲"人话"，公式能省则省。

---

## 一句话版

> 头上贴电极 → 录到微弱的电波 → 去掉噪声 → 每 2 秒切一段 → 把"22 个通道的波形"压成"4 个数" → 判"左手还是右手" → 连续 3 次一致才发指令 → 游戏执行。

整条链就是**一个翻译过程**：从"电压波形"翻译成"左/右"。

---

## 第 0 步｜脑电是什么，为什么能看出左右手

头皮上的电压只有**几十微伏**（一节 5 号电池是 1.5 伏，差了几万倍），像隔着墙听屋里说话，能听到但很糊。

能分左右，是因为一个生理事实：**想象左手动时，右脑运动区的 mu/beta 节律（8–30 Hz）会变弱**；想象右手动时，左边变弱。电极放在 C3/C4 附近就能看到这个差别。

所以我们要找的不是"某个神奇波形"，而是**"哪边变弱了"**。

---

## 第 1 步｜滤波：先把噪声赶出去

原始信号里混着三类东西：

| 噪声 | 来源 | 怎么处理 |
|---|---|---|
| 50 Hz 工频 | 插座、电脑、灯 | 陷波器（只掐掉 50 Hz 这一根） |
| 低频漂移 | 出汗、电极松动、眨眼 | 8 Hz 高通（低于 8 Hz 的全不要） |
| 高频肌电 | 咬牙、皱眉、脖子动 | 30 Hz 低通（高于 30 Hz 的全不要） |

**比喻**：像调音台，先把电流"嗡嗡声"、喘气声、牙齿"咔咔"声都削掉，只留人声。

再做一步 **CAR（共平均参考）**：每个电极减去"所有电极的平均"。为什么有用？因为眨眼、工频这类干扰是**所有电极一起动的**，减掉平均值就把共同噪声抵消了，各自特有的脑电保留下来。

> 一句话：滤波 = 只留 8–30 Hz 的脑电，并扣掉大家共同背的锅。

---

## 第 2 步｜切窗：用取景框扫过连续画面

模型没法处理"无限长的信号"，得切成小段：

- **窗长 2.0 秒**：太短看不出节律，太长反应慢。
- **步长 0.5 秒**：每半秒挪一次框，所以每 0.5 秒就能给一个新判断。

**比喻**：拿一个 2 秒宽的取景框，沿时间轴每半秒挪一格。相邻两格有 1.5 秒重叠——这是故意的，为了让判断连续、不跳。

> 为什么是 2.0 / 0.5？这是团队冻结的契约，改了会破坏游戏节奏和验收口径。

---

## 第 3 步｜特征：把"22 通道 × 2000 个点"压成"4 个数"

一个 2 秒窗、22 个通道、250 Hz，就是 **22 × 500 = 11000 个数字**。直接扔给分类器，样本不够、噪声太大。所以要"提特征"。

### 3.1 CSP：找一副"配方"，把左右手的差别放大

**比喻**：你有 22 种原料，想做一杯能喝出"咸/甜"区别的饮料。CSP 就是帮你找到**最佳配比**——按这个比例混，咸的那杯和甜的那杯差距最大。

做法（不用记公式）：
1. 统计"左手时各通道怎么一起波动"和"右手时怎么一起波动"；
2. 找一组权重，让左手在这组权重下的能量大、右手小（另一组反过来）；
3. 每个窗口用这组权重加权求和，得到少数几个数。

**关键点**：这组权重是"学"出来的，必须和模型一起存下来；在线时只是一次乘法，很快。

### 3.2 取对数：把"很大/很小"拉回同一把尺子

能量值可能差几百倍，取 `log` 后变成"差几个数量级"，数值更稳，分类器也更好处理。

### 3.3 黎曼切空间：另一种"看差别"的方式

**比喻**：不看"每个通道多大"，而看"**通道之间谁跟谁一起动**"——把 22 个通道两两之间的关系画成一张表（协方差矩阵）。

问题是：这些"表"住在一个**弯曲的表面**上（数学上叫正定矩阵流形），不能直接当普通数字用。做法是先找到这些表的"平均位置"，再把每张表"摊平"到平均位置旁边的平面上，变成普通向量。

好处：对"电极戴歪了、阻抗变了"这种整体混合不敏感，换人换天更稳；代价是算得比 CSP 慢。

> 两条路线，CSP 快、黎曼稳，我们都测了。

---

## 第 4 步｜分类：在 4 维空间里画一刀

特征只有 4 个数（或切空间后的几十个数），分类器要做的就一件事：**画一个分界面，把"左"和"右"分开**。

**LDA（线性判别分析）** 就是画一个"最合理"的平面：让两类中心离得尽量远、各自尽量聚。

**比喻**：桌上一堆红豆绿豆，你拿一把直尺当刀切下去，LDA 帮你找"切在哪、什么角度，两堆分得最干净"。

输出不是"左/右"两个字，而是**两个概率**（比如 0.72 / 0.28），后面要用这个概率做安全判断。

---

## 第 5 步｜稳定化：不许"一闪而过"就发指令

每 0.5 秒都有一个新判断，如果直接发出去，游戏角色会疯狂抽搐。所以加三道闸：

| 闸门 | 大白话 |
|---|---|
| EMA 平滑 | 新判断只占 40% 权重，和之前的结论混一混，别被一次抖动带跑 |
| 连续 3 次一致 | 想换指令？连续 3 次都说是同一个才行（"试用期转正"） |
| 置信度 ≥ 0.6 | 概率不到 0.6 就当没看清，**不猜** |

不满足条件时，输出 **idle**——注意，idle 不是"识别到你在休息"，而是"**这次我不发动作**"，是一种安全状态。

> 这一点很重要：模型没训练、模型文件丢了，输出的是 0.5/0.5 的均匀概率，天然低于 0.6 → 自动 idle。**所以不可能出现"随机乱发左右"**，这是设计保证，不是靠人自觉。

---

## 第 6 步｜发消息：游戏只认一种格式

解码器最后发一个 JSON，字段固定（`label`、`label_id`、`confidence`、`probs`、`state` 等）。游戏只读这些字段，所以**换模型不用改游戏**。

`label = "idle"` 时 `label_id` 一定是 `-1`；反之亦然。这个对应关系是硬约定。

---

## 第 7 步｜怎么"考"它才不算作弊

### 7.1 训练/测试必须分开时段

**比喻**：拿同一套题既当练习又当考试，分数必然虚高。所以用**前一次记录训练、后一次记录测试**（0train → 1test），模拟"换个时段还用"。

还有一种更狠的考法：**留一受试**——8 个人训练，考第 9 个人，轮流当考生。测的是"新用户不校准能不能用"。

### 7.2 用 Kappa，不用准确率

二分类瞎猜也有 50% 准确率。Kappa 把"瞎猜也能中的部分"扣掉：

```
Kappa = 2 × 准确率 − 1   （二分类、两类均衡时）
```

- 准确率 75% → Kappa 0.5（不错）
- 准确率 55% → Kappa 0.1（基本等于瞎猜）

判据 0.3 ≈ 准确率 65%，是脑机接口领域的常用门槛。**注意：0.3 不是"准确率 30%"。**

### 7.3 窗口级 vs trial 级

- **窗口级**：每 0.5 秒判一次，对错都算，样本多、噪声大、分数偏低。
- **trial 级**：一个 trial 里取 3 个窗口，**投票**（2 票就算赢），再和这个 trial 的真标签比。

两者单位不同，**不能相减说"投票提升了多少"**。

### 7.4 ITR：每分钟能可靠传几次意图

```
ITR ≈ [1 + p·log2(p) + (1−p)·log2(1−p)] / 2秒 × 60   （比特/分钟）
```

p 是准确率。p 越接近 1，每分钟传得越多；p 接近 0.5，ITR 接近 0（传的都是噪声）。

## 第 8 步｜为什么"在线"比"离线"难：直播不能剪辑

离线分析可以**把整段录音倒回去再修**（零相位滤波，前后各滤一遍，没有延迟）。
在线是**直播**，只能看已经发生的事，还必须有延迟。

更麻烦的是：滤波器有"记忆"（内部状态）。如果你每 0.5 秒切一段、每段都把记忆清零，接缝处就会"咔哒"一声——信号跳变，特征乱抖，判断乱跳。

所以在线必须：**因果滤波 + 把上一段的记忆原样传给下一段**。这是红线，不是优化项。

---

## 第 9 步｜我们试过的改进，为什么"没变化"

有人会问：做个"对齐"不就好了？

**欧氏对齐（EA）** 的大白话：先把每个时段的信号"音量"调到一样，再比较。

但 CSP 和黎曼有个数学性质：**你给信号做一个"整体线性变换"（相当于换个音量/换个坐标系），它们学到的结论会自动跟着变，算出来的特征几乎不变**。就像你调了音量旋钮，但后面接着一个自动音量平衡器——白调。

所以前三条改进（两种对齐、CSP 正则化）和基线**逐位一致**，这是数学必然，不是偷懒。

**子带滤波（FBCSP）** 的大白话：把音乐拆成低音、中音、高音几条轨，每条单独处理再合并。听起来更细，但**每条轨分到的样本更少**，反而估不准，实测更差。

## 名词对照表（讲的时候可以照着换词）

| 术语 | 大白话 |
|---|---|
| 通道 / 电极 | 贴在头上的小金属片，一个算一路 |
| 陷波 / 带通 | 掐掉某一根频率 / 只留一段频率 |
| CAR | 每个电极减去大家的平均值，抵消共同噪声 |
| 窗长 / 步长 | 取景框多宽 / 每多久挪一次 |
| CSP | 找最佳"配方"把两类差别放大 |
| 协方差矩阵 | "谁跟谁一起波动"的表格 |
| 黎曼切空间 | 把弯曲表面上的表格摊平成普通数字 |
| LDA | 画最合理的一刀把两类分开 |
| 置信度 | 模型对自己判断的把握，0–1 |
| idle | 这次不发动作（安全状态） |
| Kappa | 扣掉瞎猜后的一致性 |
| ITR | 每分钟能可靠传几个意图 |
| 因果滤波 | 只用过去的数据，直播专用 |
| trial | 一次完整的"想象—休息"回合 |
| 伪在线 | 按块喂数据、不重训，模拟在线 |

## 三个最容易讲错的点

1. **Kappa 0.3 ≠ 准确率 30%**，二分类时它约等于准确率 65%。
2. **离线的"3 窗投票"（2/3 即可）≠ 在线的稳定化**（连续 3 次全一致 + EMA + 0.6 门限），两者不能混着说。
3. **idle 不是"检测到静息"**，是"这次不发布动作"；模型缺失时靠"均匀概率 < 0.6"自动落到 idle。
