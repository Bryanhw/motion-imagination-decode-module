### T2 · D2（10/21）：做 3 个演示配置文件（Git 提交物）

> 依赖顺序：先造样本 → 再写配置。参考模板 `configs/demo_replay.yaml`（已切 CSP 口径）。

**2a｜造规律切换的 replay 样本**（现成脚本已支持）：

```powershell
python scripts/make_sample_data.py --out data/sample_switch.npy --seconds 60 --label-period 4
```

- `--label-period 4` = 每 4 秒左右交替，正合"左、右、左、右"演示效果。
- 独立成一个样本（`sample_switch.npy`），不污染现有 `demo_replay.yaml` 用的 `sample_continuous.npy`。

**2b｜`configs/demo_replay_switch.yaml`**：replay 指向 `data/sample_switch.npy`。

验证：

```powershell
python -m bci_decoder.cli run --config configs/demo_replay_switch.yaml --chunks 240
```

→ 台面 label 应呈 **左/右/左/右** 规律切换。

**2c｜`configs/demo_weak.yaml`**：模拟弱信号 → 置信度低于门限 → **稳定 `idle`**。

验证：`... --config configs/demo_weak.yaml --chunks 200` → 全程 `idle`，不左右乱跳。

**2d｜`configs/demo_nomodel.yaml`**：让 `model_path` 指向**不存在的模型** → 未训练 → **恒 `idle`**。

验证：`... --config configs/demo_nomodel.yaml --chunks 10` → 首条即 `idle`，报告模型缺失但**不崩、不发随机指令**。
