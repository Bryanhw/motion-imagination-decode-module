## E. 异常兜底（预设，不临场发挥）

| 场景 | 处置 |
|---|---|
| ws 断开 / 游戏无响应 | **切 keyboard 模式**并口播声明"这是工程演示，不是实时解码" |
| 模型缺失 / 加载失败 | 系统**必须输出 idle**（红线），改用键盘演示，不现场训练 |
| 置信度持续偏低 | 输出 idle，解释"宁可不动也不乱动"的设计原则 |
| 投屏/录屏失败 | 放弃投屏，改口述 + 事后补录屏；不跳过安全演练 |
| 网络异常 | 无需外网；确认 ws 本地端口未被占用 |
| 临时要求"换成 XXX 算法" | **拒绝**：现场只演示冻结配置，改进路线在报告 §8.1 |
