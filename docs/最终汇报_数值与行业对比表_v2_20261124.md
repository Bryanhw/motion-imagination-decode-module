## 二、一页优势 vs 不足（可直接投屏的总结页）

### 我们做到的（先讲诚实的好结果）

1. **链路达标、余量充足**：核心实时指标全部命中预算线——算力延迟 p95 = 3.7 ms（预算 <50 ms，余量 >10 倍）；长跑 34.9 min 零崩溃、零 error、内存无增长（门槛 30 min）。
2. **“个人校准”方向被证明有效**：同一套公开数据下，校准后 Kappa 从 ≈0.19（接近乱猜）升到 **0.36**，比免校准提升 Δ+0.17；这是本项目叙事主线的核心证据。
3. **Trial 级口径更亮眼**：对同一数据用每 trial 内 3 窗投票，CSP 0.466 / Riemann 0.481，显著超过 0.3 达标线。
4. **ITR 处于常见区间**：7.22 / 6.84 bits/min，和同类 MI 系统（个位数 bits/min 量级）相当；个别受试可达 ≈12.0。

### 我们必须如实讲清的不足（不藏短）

1. **免校准跨被试 ≈ 随机（Kappa 0.19）**：和领域共识一致——无校准跨被试本来就难；所以产品必须走“个人校准”，这正是我们的设计主线。
2. **窗口级 Kappa 0.36 偏低（保守口径）**：每 0.5s 一个窗、单窗噪声大；同一数据 trial 级三窗投票后 0.466 / 0.481。**对外讲时说明“取保守口径”**，避免被误读为“低了就不好”。
3. **端到端 ≤3 s，瓶颈在生理窗口**：2 秒攒窗是物理约束（脑电节律要用够时长才稳），不是我们算法慢——这是“脑电控制”类系统固有的延迟来源，定位为“当前生理约束下的合理值”。
4. **个体差异 / BCI illiteracy**：校准后仍有弱受试（S02 / S05 / S06 增益很小或≈0）；我们设计了**试玩门**（能玩才交付，不稳就加数据），不承诺任何真人数值。
